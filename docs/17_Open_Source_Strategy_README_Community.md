# 17 — SilicaRAW Open Source Strategy / README / Community Plan

Status: GO WITH CONDITIONS

## Principle

Be ambitious, but honest. Be beautiful, but practical. Be open, but safe.

## Positioning

README hero:

```md
# SilicaRAW

Open-source RAW photo editing for Apple Silicon.

Metal-first editing. Local-first workflow. MLX-powered tools when you need them.
```

## First 10 Seconds

A GitHub visitor should see:

- Name
- One-line description
- Screenshot/GIF
- Current status
- Tech stack
- Why it exists
- How to try/build
- How to contribute

## Required Community Files

- README.md
- ROADMAP.md
- CONTRIBUTING.md
- CODE_OF_CONDUCT.md
- SECURITY.md
- LICENSE
- Issue templates
- PR template

## Star Hooks

- Rust
- Tauri
- Metal
- MLX
- Apple Silicon
- RAW editor
- Local-first
- Open source
- Apple-like UI
- MCP-ready later

## Avoid Overhype

Do not say:

- Lightroom killer
- Perfect AI editor
- Supports every camera
- Production-ready before true

## Launch Requirements

Before public beta:

- README polished
- Hero screenshot/GIF
- Build instructions tested
- Roadmap public
- Issue templates
- Known limitations
- License decided
- Sample/model asset licensing clear

## Final Verdict

GO WITH CONDITIONS.

Need final license, README draft, CONTRIBUTING, SECURITY, issue templates, screenshots/GIFs, sample asset manifest.
