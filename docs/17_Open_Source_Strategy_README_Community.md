# 17 — SilicaRAW Open Source Strategy / README / Community Plan

Status: GO WITH CONDITIONS

## Principle

Be ambitious, but honest. Be beautiful, but practical. Be open, but safe.

## Positioning

README hero:

```md
# SilicaRAW

Early-stage open-source RAW photo editing for Apple Silicon.

Local-first workflow. Non-destructive editing goals. RAW, color, Metal, MLX, plugins, and MCP advance only when fixture-backed evidence supports them.
```

## First 10 Seconds

A GitHub visitor should see:

- Name
- One-line description
- Screenshot/GIF
- Current status
- Tech stack
- Why it exists
- How to try/build
- How to contribute

## Required Community Files

- README.md
- ROADMAP.md
- CONTRIBUTING.md
- CODE_OF_CONDUCT.md
- SECURITY.md
- LICENSE
- Issue templates
- PR template

## Current Star Hooks

- Rust
- Tauri
- Apple Silicon
- RAW editor
- Local-first
- Open source
- Apple-like UI

## Future Star Hooks

- Metal-first product viewer after the native bridge contract is implemented.
- MLX-assisted tools after the editor core is trustworthy.
- MCP-ready integrations after permissioning and security gates exist.

## Avoid Overhype

Do not say:

- Lightroom killer
- Perfect AI editor
- Supports every camera
- Production-ready before true

## Launch Requirements

Before public beta:

- README polished
- Hero screenshot/GIF
- Build instructions tested
- Roadmap public
- Issue templates
- Known limitations
- License decided
- Sample/model asset licensing clear

GO WITH CONDITIONS.
