## Goal

Generate and display real histogram data for supported preview states.

## Scope

- Add real histogram data for supported preview states.
- Cache histogram data only as disposable cache.
- Represent missing/blocked histogram states honestly.
- Do not add histogram claims for unsupported sources.

## Acceptance Criteria

- Histogram cache can be safely deleted.
- Histogram reflects current supported preview/edit state.
- Missing, blocked, and unsupported states are explicit.
- Original files remain untouched.

## Validation

```bash
cargo test -p silica-render -p silica-storage -p silica-core
scripts/harness/check.sh
```

## Completion State

Complete.

- Render computes 256-bin RGB and luminance histograms from real RGB pixel buffers.
- Export computes adjusted JPEG/JPG histogram data through the same local Develop adjustment order used by preview/export.
- Storage records histogram cache rows under disposable `render-cache/` only.
- Core exposes `get_photo_histogram` for the current committed Develop state, with explicit ready, missing, blocked, and unsupported statuses.
- Desktop exposes the histogram command and static UI renders real luminance bars instead of a fake placeholder.
- Histogram cache clear remains covered by the existing disposable cache clear path.

## Stop Gates

Stop if histogram cache becomes durable recovery state or silently reads/writes originals outside existing boundaries.
