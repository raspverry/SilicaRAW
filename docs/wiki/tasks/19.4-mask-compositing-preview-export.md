# Task 19.4: Mask Compositing in Preview and Export

## Goal

Apply committed manual masks consistently in preview and export, or block unsupported combinations honestly.

## Read Before Work

- [Task 19.3 Brush Mask Storage and Rasterization](19.3-brush-mask-storage-rasterization.md)
- [Phase 19 Brief](../phases/phase-19-manual-masks.md)
- [Edit Graph](../topics/edit-graph.md)

## Files

- `crates/silica-render/`
- `crates/silica-export/`
- `crates/silica-core/`
- `scripts/harness/`

## Scope

- Apply committed manual mask semantics to supported preview and export paths.
- Keep preview and export behavior aligned within documented tolerance.
- Record mask-related export evidence where the current export evidence model supports it.
- Block unsupported mask/export combinations before writing output.
- Do not add AI masks, MLX masks, new export formats, broad RAW claims, or hidden fallback compositing.

## Acceptance Criteria

- Preview and export agree for supported committed manual mask states.
- Unsupported mask states block before output is written.
- Masked edits are represented in undoable history through committed edit graph state.
- Export output path safety and original hash preservation remain covered.

## Validation

```bash
cargo test -p silica-render -p silica-export -p silica-core
scripts/harness/check.sh
```

## Stop Gates

Stop if export would silently ignore an active committed mask or preview/export semantics diverge.
