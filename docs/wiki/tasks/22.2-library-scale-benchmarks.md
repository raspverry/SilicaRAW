# 22.2: Library Scale Benchmarks

## Goal

Record local benchmark evidence for the paged Library query path at 1k, 10k, and 50k catalog rows.

## Scope

- Seed synthetic catalog rows in a temporary local library.
- Measure the existing typed `silica-storage::query_library_photos` path.
- Record machine metadata, dataset shape, query timings, and a lightweight render-adjacent page-model timing.

## Non-Goals

- Do not create original photo files.
- Do not decode RAW files.
- Do not generate thumbnails.
- Do not benchmark GPU, Metal, or native viewer rendering.
- Do not present the results as universal performance guarantees.

## Validation

```bash
python3 scripts/harness/run-library-scale-benchmarks.py
python3 scripts/harness/check-library-scale-benchmark.py
scripts/harness/check.sh
```
