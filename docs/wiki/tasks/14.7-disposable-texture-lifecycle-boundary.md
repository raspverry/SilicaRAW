# Task 14.7: Disposable Texture Lifecycle Boundary

## Goal

Define a minimal disposable texture lifecycle boundary for the native viewer bridge.

## Read Before Work

- [Task 14.6 Render Request Boundary](14.6-render-request-boundary.md)
- [Metal Render Pipeline Specification](../../08_Metal_Render_Pipeline_Specification.md)
- [Data Safety](../topics/data-safety.md)

## Files

- `apps/desktop/src-tauri/src/native_metal_viewer.rs`
- `crates/silica-render/src/lib.rs`
- `docs/wiki/topics/metal-rendering.md`
- `docs/wiki/topics/data-safety.md` if cache safety rules change

## Scope

- Define disposable texture/cache lifecycle states.
- Define cleanup on photo change, library close, and app close.
- Keep texture cache separate from catalog state.
- Keep cache rebuildable and safe to clear.

## Acceptance Criteria

- Texture lifecycle states are explicit.
- Cleanup behavior is testable.
- No original file path is used as a write destination.
- No catalog or sidecar state is written by texture lifecycle management.

## Validation

