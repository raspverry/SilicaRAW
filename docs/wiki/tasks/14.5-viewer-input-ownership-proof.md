# Task 14.5: Viewer Input Ownership Proof

## Goal

Prove native viewer input handling without stealing web UI control interaction.

## Read Before Work

- [Task 14.1 AppKit/Metal Viewer Bridge Contract](14.1-appkit-metal-viewer-bridge-contract.md)
- [Task 14.4 Resize Retina Lifecycle Proof](14.4-resize-retina-lifecycle-proof.md)

## Files

- `apps/desktop/src-tauri/src/native_metal_viewer.rs`
- `checklists/`
- `docs/wiki/topics/metal-rendering.md`

## Scope

- Record mouse down and drag on the native viewer surface.
- Record trackpad scroll and magnify on the native viewer surface.
- Verify web UI buttons, sliders, and inputs still receive interaction outside the viewer rectangle.
- Keep event logs scoped to manual proof; do not add telemetry.

## Acceptance Criteria

- Native viewer surface owns viewer-specific input only.
- Web UI controls remain responsive.
- Manual QA checklist covers mouse, drag, scroll, magnify, modifier keys if relevant, and focus behavior.
- No analytics, telemetry, or persistent input logging is added.

## Validation

```bash
cargo test -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

Manual validation must record input evidence on macOS.

## Completion State

Not started.

## Stop Gates

Stop if event ownership cannot keep native viewer input separate from web UI controls.
