# Task 18.4.1: Lens and Geometry Mutators

## Goal

Add schema-valid edit graph mutators for lens toggles, distortion, vignetting, transform, crop, rotate, and flips.

## Read Before Work

- [Task 18.3.3 Detail Panel UI QA](18.3.3-detail-panel-ui-qa.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)

- [Edit Graph Schema](../../../schemas/edit_graph.schema.json)

## Files

- `crates/silica-edit/src/lib.rs`
- `docs/wiki/topics/edit-graph.md`

## Scope

- Add typed mutators for schema-owned `lens` and `geometry` fields.
- Validate crop bounds, rotation, transform, and lens numeric ranges.
- Keep lens profile correction a boolean state only; do not add a lens profile database.
- Do not add preview, export, UI, storage, sidecar, or original metadata behavior.

## Acceptance Criteria

- Lens and geometry edits can be applied to an existing edit graph.
- Invalid crop/rotation/transform/lens values are rejected.
- Edited graphs validate and round-trip.

## Completion Notes

- Added graph-only mutators for schema-owned lens toggles, distortion, vignetting, geometry transform, rotation, flips, crop, and crop clearing.
- Kept lens profile handling as stored boolean/profile-id state only; no profile database, metadata parser, preview, export, UI, storage, or sidecar behavior was added.
- Added focused `silica-edit` tests for round-trip serialization and invalid lens/crop/rotation/transform ranges, including normalized crop frame bounds.
