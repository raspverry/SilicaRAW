# Task 14.4: Resize, Retina, and Lifecycle Proof

## Goal

Prove product-module resize, Retina scale, lifecycle, and render timing behavior under the `native-metal-viewer` feature.

## Read Before Work

- [Task 14.2 Native Viewer Feature Gate](14.2-native-viewer-feature-gate.md)
- [Task 14.3 Reserved Viewer Layout Handshake](14.3-reserved-viewer-layout-handshake.md)

- `apps/desktop/src-tauri/src/main.rs`
- `checklists/`
- `docs/wiki/topics/metal-rendering.md`

## Scope

- Record install lifecycle.
- Record drawable size changes.
- Record backing scale.
- Record render timing.
- Record cleanup or uninstall behavior for app/window close.
- Keep proof output neutral and obviously non-product image rendering.

## Acceptance Criteria

- Feature-gated tests or smoke helpers cover install lifecycle state.
- Manual runbook records resize and Retina evidence.
- Render timing is observable without blocking UI responsiveness.
- Default app path remains unchanged when feature is off.

## Validation

```bash
cargo test -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

Manual validation must run on macOS with the feature enabled and record resize, backing scale, and render timing output.

## Completion State

Completed on 2026-06-12.

Task 14.4 added:

- feature-gated product module lifecycle proof types for reserved host geometry, drawable size, backing scale, install state, resize events, render frame timing, and cleanup reason
- neutral smoke evidence through `lifecycle_smoke_evidence_is_neutral_and_reviewable`
- optional feature-on runtime evidence logging through `SILICA_NATIVE_VIEWER_LIFECYCLE_PROOF`
- [Native Viewer Lifecycle QA Checklist](../../../checklists/NATIVE_VIEWER_LIFECYCLE_QA.md)

Recorded macOS evidence:

```txt
[SilicaRAW Native Viewer] surface=develop state=uninstalled drawable=1200x675px backing_scale=1.50 resize_events=1 frames=1 last_frame_ms=16.667 preferred_fps=60 cleanup=window-closed neutral_clear_only=true frame_timing_ms=16.667 cleanup_supported=app-closed,window-closed
```

This task does not install the final product image viewer, render RAW pixels, render exposure or contrast in Metal, allocate product textures, or change the default feature-off app path.
