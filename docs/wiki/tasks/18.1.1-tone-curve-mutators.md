# Task 18.1.1: Tone Curve Mutators

## Goal

Add schema-valid edit graph mutators for tone curve mode and RGB/channel curve point data.

## Read Before Work

- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Edit Graph](../topics/edit-graph.md)
- [Edit Graph Schema](../../../schemas/edit_graph.schema.json)

## Files

- `crates/silica-edit/src/lib.rs`
- `docs/wiki/topics/edit-graph.md`

## Scope

- Add typed mutator functions for `tone.curve_mode`, `rgb_curve`, `red_curve`, `green_curve`, and `blue_curve`.
- Validate curve shape through the existing edit graph validation path.
- Reject non-finite values, out-of-range points, duplicate `x` values, and non-monotonic point order.
- Treat non-empty point curves as requiring explicit endpoints at `(0, 0)` and `(1, 1)` for the first implementation.
- Do not claim `parametric` curve behavior beyond storing a schema-valid mode unless a later explicit task adds schema-owned parameters.
- Preserve source, profile, basic, color, detail, lens, geometry, masks, metadata, and extensions.
- Keep serialization round-trips stable.
- Do not add preview, export, UI, storage, sidecar, or history behavior.

## Acceptance Criteria

- Tone curve edits can be applied to an existing edit graph.
- Invalid curve points, modes, or out-of-range values are rejected.
- Duplicate or descending `x` coordinates are rejected.
- Missing non-empty curve endpoints are rejected.
- Edited graphs validate and round-trip.
- Existing Phase 17 mutator tests still pass.

## Validation

```bash
cargo test -p silica-edit
scripts/harness/check.sh
```

## Completion State

Complete.

- `crates/silica-edit` exposes `apply_tone_curve`.
- The mutator accepts schema-owned RGB, red, green, and blue point curves.
- Non-empty curves must start at `(0, 0)`, end at `(1, 1)`, and use strictly increasing `x` values.
- `Parametric` mode is rejected by the mutator because v0.1 has no schema-owned parametric parameters.
- The task added no preview, export, UI, storage, sidecar, or history behavior.

## Stop Gates

Stop if tone curve behavior needs renderer/export claims before graph validation is complete, if shipped parametric state must be hidden under `extensions`, or if schema fields outside `tone` are needed.
