# Task 16.5: Append-Only Action Log

## Goal

Add an append-only action log through Core APIs for sensitive local actions and future permissioned extension work.

## Scope

- Add action log storage contract and migration.
- Add Core API for append-only log writes.
- Record actor, action, target, timestamp, side-effect category, and evidence reference.
- Log export, cache clear, backup/restore boundary, sidecar sync, and future permission-sensitive actions.
- Keep plugin/MCP/MLX runtime out of scope.

## Acceptance Criteria

- Action log rows are append-only through Core APIs.
- Extension-facing code cannot write raw action rows directly.
- Original file mutation remains forbidden.
- Action log records enough context for future permission/audit work.
- Existing local alpha flows still pass.

## Validation

```bash
cargo test -p silica-storage -p silica-core
scripts/harness/check.sh
```

## Completion State

Complete. Task 16.5 adds catalog schema version 8 with action-log side-effect and evidence columns, storage append/list APIs, Core append/list wrappers, and Core-side logging for import by reference, sidecar write, JPEG export, RAW-derived export, and disposable cache clear. Plugin, MCP, MLX, permission UI, and extension runtime remain out of scope.

## Stop Gates

Stop if direct raw SQL permission is introduced, if extension runtime starts, or if action logging can be skipped by sensitive Core operations.
