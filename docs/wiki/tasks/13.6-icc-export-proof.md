# Task 13.6: ICC Export Proof

## Goal

Prove exported sRGB and Display P3 JPEG files embed the expected ICC profiles before enabling broader export claims.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Color Management](../topics/color-management.md)
- [Golden Image and Tolerance Policy](../../../checklists/GOLDEN_IMAGE_TOLERANCE_POLICY.md)
- [Task 13.5 Color Support Matrix](13.5-color-support-matrix.md)

## Files

- `crates/silica-export`
- `crates/silica-render`
- `checklists/`
- `docs/wiki/topics/color-management.md`

## Scope

- Keep sRGB as the default export target.
- Add Display P3 export only as an explicit target after probe evidence supports it.
- Inspect exported files for expected ICC/profile embedding.
- Record output file hash, output profile, separate output path, and original hash preservation.
- Add a manual Preview.app or Photos comparison checklist.

## Acceptance Criteria

- sRGB export ICC behavior is proven or explicitly blocked.
- Display P3 export ICC behavior is proven or explicitly blocked.
- Existing original-overwrite protection remains intact.
- File/profile inspection is not described as full visual color correctness.

## Validation

```bash
cargo test -p silica-export -p silica-render
scripts/harness/check.sh
```

## Completion State

Not started.

## Stop Gates

Stop if ICC embedding cannot be proven without a new dependency decision or if export would overwrite originals.
