# Task 13.6: ICC Export Proof

## Goal

Prove exported sRGB and Display P3 JPEG files embed the expected ICC profiles before enabling broader export claims.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Color Management](../topics/color-management.md)
- [Golden Image and Tolerance Policy](../../../checklists/GOLDEN_IMAGE_TOLERANCE_POLICY.md)
- [Task 13.5 Color Support Matrix](13.5-color-support-matrix.md)

## Files

- `crates/silica-export`
- `crates/silica-render`
- `checklists/`
- `docs/wiki/topics/color-management.md`

## Scope

- Keep sRGB as the default export target.
- Add Display P3 export only as an explicit target after probe evidence supports it.
- Inspect exported files for expected ICC/profile embedding.
- Record output file hash, output profile, separate output path, and original hash preservation.
- Add a manual Preview.app or Photos comparison checklist.

## Acceptance Criteria

- sRGB export ICC behavior is proven or explicitly blocked.
- Display P3 export ICC behavior is proven or explicitly blocked.
- Existing original-overwrite protection remains intact.
- File/profile inspection is not described as full visual color correctness.

## Validation

```bash
cargo test -p silica-export -p silica-render
scripts/harness/check.sh
```

## Completion State

Complete as of 2026-06-12.

Task 13.6 added:

- ICC embedding through the existing `image` JPEG encoder API.
- sRGB ICC embedding for the default `export_jpeg_srgb` path.
- Explicit Display P3 ICC embedding through `export_jpeg_with_color_profile`.
- JPEG ICC inspection via `inspect_jpeg_icc_profile`.
- Output SHA-256 and ICC profile SHA-256 fields in `JpegExportResult`.
- Original overwrite protection coverage for the expanded export path.
- [Color Export Manual QA Checklist](../../../checklists/COLOR_EXPORT_MANUAL_QA.md).

Evidence:

```txt
srgb export -> embedded ICC true, ICC SHA-256 2b3aa1645779a9e634744faf9b01e9102b0c9b88fd6deced7934df86b949af7e, original unchanged
display_p3 explicit export -> embedded ICC true, ICC SHA-256 recorded from the active macOS system profile, original unchanged
```

The local Display P3 baseline profile hash was `0ff6958f98684c61f6bbdce1368ddeaf3873baf84545baba482e920d92a914c0`, but macOS runner images may ship byte-different Display P3 ICC profiles. Product classification must use ICC profile semantics such as RGB XYZ tags, while export records preserve the actual embedded ICC SHA-256 for audit evidence.

This is file/profile inspection evidence only. It does not prove visual color correctness or parity with Preview.app, Photos, Lightroom, Capture One, or camera vendor renderers.

## Stop Gates

Stop if ICC embedding cannot be proven without a new dependency decision or if export would overwrite originals.
