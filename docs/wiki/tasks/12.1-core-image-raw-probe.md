# Task 12.1: Feature-Gated Core Image RAW Probe

## Goal

Add a macOS-only, non-default Core Image RAW probe in `silica-decode`.

## Read Before Work

- [Phase 12 RAW Proof Brief](../phases/phase-12-raw-proof.md)
- [RAW Decoding](../topics/raw-decoding.md)
- [Architecture Patch](../../20_v1_1_Architecture_Patch.md)
- [Dependencies Policy](../../DEPENDENCIES.md)

## Files

- `crates/silica-decode`
- `docs/DEPENDENCIES.md` if any dependency is added or changed
- Phase 12 docs if task status changes

## Scope

- Feature gate name: `core-image-raw-probe`.
- The feature must be non-default.
- The probe must compile only where the chosen macOS/Core Image path is available.
- Normal local alpha behavior must not call the probe.
- No LibRaw dependency.

## Acceptance Criteria

- Probe is feature-gated and not part of normal local alpha behavior.
- No LibRaw dependency is added.
- Any macOS binding dependency is documented in `docs/DEPENDENCIES.md`.
- Unsupported platforms fail gracefully or keep the feature unavailable without affecting default builds.

## Validation

```bash
cargo test -p silica-decode --features core-image-raw-probe
scripts/harness/check.sh
```

## Stop Gates

Stop before implementation if the Core Image binding choice requires a large dependency or unclear license. Record the dependency decision first.

## Notes for LLM Agents

Do not implement product RAW decoding, UI rendering, color management, LibRaw, or fixture support in this task.
