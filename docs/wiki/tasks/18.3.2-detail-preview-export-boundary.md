# Task 18.3.2: Detail Preview and Export Boundary

## Goal

Define and implement the smallest honest supported detail preview/export behavior, with explicit blocked states where renderer support is not ready.

## Read Before Work

- [Task 18.3.1 Detail Mutators](18.3.1-detail-mutators.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Data Safety](../topics/data-safety.md)

## Files

- `crates/silica-render/src/lib.rs`
- `crates/silica-core/src/lib.rs`
- `crates/silica-export/src/lib.rs`
- `apps/desktop/src-tauri/src/main.rs`

## Scope

- Carry committed detail state through runtime requests.
- Implement only detail effects that can be previewed and exported consistently.
- Return explicit unsupported states for effects that cannot yet be rendered honestly.
- If no detail effect can be previewed and exported consistently, keep persistence and UI enablement blocked.
- Commit supported detail changes as one undoable checkpoint.
- Do not add MLX denoise, fallback model paths, or broad quality claims.

## Acceptance Criteria

- No Detail effect is treated as supported until renderer/export semantics exist.
- Non-neutral Detail preview returns an explicit unsupported state and no preview bytes.
- Detail commit returns `UnsupportedEdit` and does not write catalog edit state or history.
- JPEG export and histogram block active committed non-neutral Detail state instead of silently ignoring it.
- Neutral Detail state still flows through preview/export requests and desktop command responses.

## Completion Notes

- `silica-render` carries Detail values on preview/export requests and marks non-neutral Detail preview/export as unsupported.
- `silica-export` accepts Detail request fields but rejects non-neutral values before writing pixels.
- `silica-core` exposes Detail preview commands, blocks Detail commit, blocks active committed non-neutral Detail export/histogram, and preserves neutral existing editor behavior.
- `silica-desktop` exposes Detail state in edit responses and maps blocked Detail commit to `unsupportedEdit`.
- The current supported Detail runtime set is empty; Task 18.3.3 must show honest disabled/blocked UI states, not active sharpening/noise-reduction controls.

## Validation

```bash
cargo test -p silica-render -p silica-core -p silica-export -p silica-desktop
scripts/harness/check.sh
```

## Stop Gates

Stop if unsupported detail behavior would be hidden behind no-op success or excessive fallback paths.
