# Task 18.2.1: HSL Color Mixer Mutators

## Goal

Add schema-valid edit graph mutators for per-channel hue, saturation, and luminance controls.

## Read Before Work

- [Task 18.1.3 Tone Curve Panel UI QA](18.1.3-tone-curve-panel-ui-qa.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Edit Graph](../topics/edit-graph.md)
- [Edit Graph Schema](../../../schemas/edit_graph.schema.json)

## Files

- `crates/silica-edit/src/lib.rs`
- `docs/wiki/topics/edit-graph.md`

## Scope

- Add typed mutators for red, orange, yellow, green, aqua, blue, purple, and magenta HSL channels.
- Validate hue, saturation, and luminance ranges through the existing graph validation path.
- Preserve all unrelated edit graph sections.
- Do not add preview, export, UI, storage, sidecar, or color grading behavior.

## Acceptance Criteria

- HSL edits can be applied to an existing edit graph.
- Invalid channel names or out-of-range values are rejected.
- Edited graphs validate and round-trip.

## Validation

```bash
cargo test -p silica-edit
scripts/harness/check.sh
```

## Stop Gates

Stop if HSL behavior requires color-correctness claims before graph validation is complete.
