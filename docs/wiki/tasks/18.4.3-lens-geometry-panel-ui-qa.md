# Task 18.4.3: Lens Geometry Panel UI and QA

## Goal

Expose supported lens, crop, rotate, and geometry controls in Develop with clear non-destructive behavior.

## Read Before Work

- [Task 18.4.2 Geometry Preview Export Parity](18.4.2-geometry-preview-export-parity.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [UI Visual and Responsive QA](../topics/ui-visual-responsive-qa.md)

## Files

- `apps/desktop/static/`
- `scripts/harness/check-static-ui.py`
- `scripts/harness/check-ui-workflow-smoke.py`
- `scripts/harness/run-final-visual-qa.py`

## Scope

- Add UI controls for supported crop/rotate/flip/geometry actions.
- Present lens profile correction as unavailable unless runtime support exists.
- Keep original-file safety visible through command behavior, not extra fallback systems.
- Do not add masks, batch sync, or destructive file operations.

## Acceptance Criteria

- Geometry controls fit current responsive layouts.
- Unsupported lens features are disabled or blocked honestly.
- Static smoke covers a supported geometry interaction.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/check-ui-workflow-smoke.py
python3 scripts/harness/run-final-visual-qa.py
scripts/harness/check.sh
```

## Stop Gates

Stop if UI behavior can be mistaken for destructive source-file rotation or broad automatic lens correction.
