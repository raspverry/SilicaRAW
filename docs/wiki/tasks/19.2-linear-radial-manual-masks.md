## Scope

- Add graph-owned manual `linear_gradient` and `radial_gradient` mask helpers only after Task 19.1 confirms the schema shape.
- Keep mask geometry non-destructive and normalized to the image frame.
- Use only schema-owned `masks[].geometry` for gradient geometry and `source.kind = "manual"` for provenance.
- Define the supported `local_adjustments` keys and ranges before preview or commit; unsupported local adjustments must block visibly.
- Preview only where the renderer can honestly apply the mask semantics.
- Commit mask edits through undoable catalog history.
- Do not add brush masks, AI masks, MLX, subject/sky/background selection, plugin/MCP hooks, or broad RAW claims.

## Schema Contract From Task 19.1

```txt
linear_gradient:
  source = {"kind": "manual"}
  geometry.kind = "linear_gradient"
  geometry.start_x/start_y/end_x/end_y = normalized 0..1 frame coordinates

radial_gradient:
  source = {"kind": "manual"}
  geometry.kind = "radial_gradient"
  geometry.center_x/center_y = normalized 0..1 frame coordinates
  geometry.radius_x/radius_y = normalized >0..1 radii
  geometry.rotation = -180..180 degrees
```

Do not store gradient geometry in `mask.source`. Do not use `cache_path`, model fields, AI result fields, or arbitrary manual source extensions for manual masks.

## Acceptance Criteria

- Linear and radial manual masks validate and round-trip through `silica-edit`.
- Supported JPEG/JPG preview paths apply the same manual gradient semantics that the later export path must use.
- Unsupported preview states return explicit blocked/unsupported results.
- Commit creates undoable history without writing sidecars, exports, disposable cache as durable state, or originals.
- JPEG export blocks active manual masks until Task 19.4 adds export compositing, so export cannot silently ignore masks.

## Completion Notes

- Added `silica-edit` helpers for manual `linear_gradient` and `radial_gradient` masks with schema-owned `masks[].geometry`, manual provenance, and local `exposure`/`contrast` range checks.
- Added render/export preview contracts for manual gradient masks on disposable JPEG/JPG develop previews only.
- Added core preview and commit APIs for manual linear/radial masks, backed by undoable edit graph history.
- Added a core export guard that blocks active manual masks before JPEG output or export records are written until Task 19.4.
- Kept brush masks, AI/MLX masks, subject/sky/background selection, MCP/plugin hooks, broad RAW claims, and mask editor UI out of scope.
