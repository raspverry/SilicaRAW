# Task 13.2: Local Color Fixture Corpus and Manifest

## Goal

Create an ignored local Color Class F fixture corpus and manifest after source review.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Task 13.1 Color Fixture Source Review](13.1-color-fixture-source-review.md)
- [Synthetic Local Color Fixture Source Review](../sources/color-fixtures-synthetic-local.md)
- [Fixture Manifest Schema](../../../schemas/fixture_manifest.schema.json)

## Files

- Ignored local directory such as `.tmp/legal-color-fixtures/`
- Ignored local manifest supplied by `SILICARAW_COLOR_FIXTURE_MANIFEST`
- `docs/wiki/topics/color-management.md`

## Scope

- Download or generate only approved fixture files into ignored local paths.
- Record SHA-256, file size, width, height, profile expectation, subclass, and source provenance.
- Keep manifest paths relative and safe.
- Keep actual probe result fields in a blocked/not-recorded state until Task 13.4.

## Acceptance Criteria

- Fixture media and local manifest are not committed.
- The local manifest follows `schemas/fixture_manifest.schema.json`.
- The manifest contains `srgb_jpeg`, `display_p3_jpeg`, and `untagged_jpeg` Class F entries.
- Original fixture hashes are recorded before probe work.

## Validation

```bash
git status --short
python3 scripts/harness/check-fixture-manifest-contract.py
```

## Stop Gates

Stop if the manifest needs absolute paths, unsafe relative paths, fake profile labels, or unlicensed files.
