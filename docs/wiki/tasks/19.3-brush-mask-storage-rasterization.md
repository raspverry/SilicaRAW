# Task 19.3: Brush Mask Storage and Rasterization

## Goal

Add manual brush mask durability and rasterization while keeping durable mask data separate from disposable render/cache artifacts.

## Read Before Work

- [Task 19.2 Linear and Radial Manual Masks](19.2-linear-radial-manual-masks.md)
- [Phase 19 Brief](../phases/phase-19-manual-masks.md)
- [Edit Graph](../topics/edit-graph.md)
- [Catalog](../topics/catalog.md)
- [Data Safety](../topics/data-safety.md)

## Files

- `crates/silica-edit/`
- `crates/silica-render/`
- `crates/silica-storage/`
- `crates/silica-core/`

## Scope

- Represent manual brush mask data in the edit graph or a documented durable catalog-owned structure from Task 19.1.
- Rasterize brush masks only into disposable library-local cache artifacts.
- Avoid per-slider writes that duplicate large brush data unnecessarily.
- Keep history transactions non-destructive and original-safe.
- Do not add AI masks, MLX rasterization, plugin/MCP access, or sidecar auto-write.

## Acceptance Criteria

- Brush mask data is durable, schema-valid, and non-destructive.
- Disposable raster artifacts are reproducible from durable mask data and can be cleared without data loss.
- Brush edits do not bloat unrelated per-slider edit commits.
- Storage and render tests prove originals remain unchanged.

## Validation

```bash
cargo test -p silica-edit -p silica-render -p silica-storage -p silica-core
scripts/harness/check.sh
```

## Stop Gates

Stop if disposable raster cache bytes become the only durable representation of a brush mask.
