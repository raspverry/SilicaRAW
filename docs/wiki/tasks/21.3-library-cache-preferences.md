# Task 21.3: Library and Cache Preferences

## Goal

Move supported Library and Cache settings into the Phase 21 Preferences surface without expanding file-system mutation beyond existing disposable cache boundaries.

## Status

Completed on 2026-06-17. Preferences now expose Library default path storage and Cache status/clear controls. Cache status is read-only and reports disposable cache paths, bytes, and cache record count. Cache clear continues to use the existing disposable-only boundary for `thumbnails/`, `previews/`, `render-cache/`, and `ai-cache/`. Startup behavior, recents behavior, export defaults, Color preferences, Export preferences, and Advanced agent/plugin/MCP controls remain unchanged.

## Scope

- Add read-only disposable cache status for the active library.
- Move the existing disposable cache clear action into the Preferences Cache pane.
- Keep cache clearing limited to `thumbnails/`, `previews/`, `render-cache/`, and `ai-cache/`.
- Add app-session Library storage preferences only for default library path selection and reset.
- Keep startup behavior unchanged in this task.
- Keep Preferences Color, Export, and Advanced controls disabled.

## Non-Goals

- Do not add original-file delete, move, copy, relink, or cleanup actions.
- Do not clear exports, sidecars, backups, catalog data, action logs, or original referenced files.
- Do not add cache quota eviction or background cache pruning.
- Do not change launch restore behavior or recents behavior.
- Do not change export defaults.
- Do not start MCP, plugin runtime, agent bridges, telemetry, cloud sync, or auto-update.

## Acceptance Criteria

- Cache status reflects real disposable cache paths, byte sizes, and cache record count.
- Cache clear from Preferences uses the existing disposable cache boundary.
- Library default path preference persists and resets through app-level session state.
- Preferences never expose dangerous original-file operations.
- Status, loading, disabled, success, and error states are visible and compact.

## Stop Gates

Stop if implementation requires deleting outside disposable cache directories, mutating original photo files, changing launch restore behavior, adding background eviction, changing export defaults, or enabling advanced agent/plugin/MCP controls.
