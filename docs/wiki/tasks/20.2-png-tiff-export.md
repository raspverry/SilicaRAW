# Task 20.2: PNG and TIFF Export

## Goal

Add PNG and TIFF export for supported local raster paths after codec behavior is covered by tests.

Status: completed on 2026-06-17. PNG/TIFF exports use the existing committed raster adjustment path, write separate sRGB files, preserve original overwrite protection, record catalog export evidence, and appear as explicit choices in the existing Export dialog. JPEG sRGB 90 remains the default preset.

## Scope

- Add explicit PNG and TIFF export formats for already-supported raster export sources.
- Reuse the existing committed edit/export adjustment path where it already applies to JPEG/JPG exports.
- Preserve output path overwrite protection for original files and same source/output identity.
- Record completed PNG/TIFF exports in the catalog `exports` table with honest `export_settings_json`.
- Keep JPEG sRGB as the conservative default setting and preset.
- Surface PNG/TIFF as explicit export format choices in the existing Export dialog.

## Non-Goals

- Do not add batch export, recent exports, or progress queues.
- Do not add metadata policy controls; Task 20.3 owns that.
- Do not add Display P3 enablement beyond the existing explicit JPEG path; Task 20.5 owns P3 export expansion.
- Do not add RAW decode support, new camera support claims, MLX, MCP, plugin runtime, cloud sync, telemetry, auto-update, or Homebrew behavior.
- Do not add new dependencies unless `docs/DEPENDENCIES.md` is updated with license/reason evidence.

## Acceptance Criteria

- PNG and TIFF exports write separate output files and never mutate originals.
- Original overwrite guard remains active for every supported format.
- Export records are stored in the catalog for PNG and TIFF with format-specific settings evidence.
- JPEG export remains compatible with existing presets, defaults, and tests.
- UI honestly shows the selected format and does not imply batch, metadata-policy, RAW, or broad color-management support.

## Stop Gates

Stop if PNG/TIFF require edit graph schema changes, if any format can overwrite originals, if output records cannot distinguish the selected format, or if the UI implies unsupported batch/metadata/RAW/color behavior.
