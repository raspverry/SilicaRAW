# Task 14.2: Native Viewer Feature Gate and Module Shell

## Goal

Add a feature-gated product native viewer module shell that is separate from Spike 001 proof code.

## Read Before Work

- [Task 14.1 AppKit/Metal Viewer Bridge Contract](14.1-appkit-metal-viewer-bridge-contract.md)
- [Phase 14 Product Metal Viewer Bridge Brief](../phases/phase-14-product-metal-viewer-bridge.md)
- [Dependencies Policy](../../DEPENDENCIES.md)

## Files

- `apps/desktop/src-tauri/Cargo.toml`
- `apps/desktop/src-tauri/src/main.rs`
- `apps/desktop/src-tauri/src/native_metal_viewer.rs`
- `docs/DEPENDENCIES.md` if dependency features or dependencies change
- `docs/wiki/topics/metal-rendering.md`

## Scope

- Add a non-default `native-metal-viewer` feature.
- Add a macOS-only product module shell.
- Keep `metal_host_spike.rs` unchanged except for references if required.
- Keep default desktop builds free of native viewer code.

## Acceptance Criteria

- `cargo check -p silica-desktop` passes without the feature.
- `cargo check -p silica-desktop --features native-metal-viewer` passes on macOS.
- The product module name and docs make clear it is not Spike 001 proof code.
- No RAW pixels, shader passes, texture cache, or UI layout changes are added.

## Validation

```bash
cargo check -p silica-desktop
cargo check -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

## Completion State

Not started.

## Stop Gates

Stop if enabling the feature requires an undocumented dependency or compiles native viewer behavior into the default app path.
