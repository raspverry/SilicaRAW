# Task 18.1.2: Tone Curve Preview, Commit, and Export Parity

## Goal

Wire validated tone curve state through draft preview, committed edit state, undo/history, and export semantics for supported image paths.

- [Task 18.1.1 Tone Curve Mutators](18.1.1-tone-curve-mutators.md)

- `crates/silica-render/src/lib.rs`
- `crates/silica-core/src/lib.rs`
- `crates/silica-export/src/lib.rs`
- `apps/desktop/src-tauri/src/main.rs`

## Scope

- Add honest draft behavior for tone curve state where renderer support exists.
- Scope the first supported runtime path to JPEG/JPG unless existing fixture-backed RAW routes already provide equivalent evidence.
- Commit one undoable checkpoint for tone curve changes.
- Ensure export uses the committed tone curve state where supported.
- Keep unsupported renderer/export states explicit.
- Block export rather than silently ignore an active committed curve that cannot be applied.
- Use generated local ramp fixtures where pixel evidence is needed; do not commit external media without source and license review.
- Do not add HSL, detail, geometry, masks, MLX, plugin, MCP, or broad RAW claims.

## Acceptance Criteria

- Draft preview does not write catalog state.
- Commit writes validated edit state and one undoable history checkpoint.
- Export applies the committed tone curve state where supported.
- Unsupported or blocked sources remain honest.
- Preview and export use the same committed tone curve semantics for supported paths.
- Original hashes remain unchanged.
- Sidecar status follows Phase 16 rules.

## Validation

```bash
cargo test -p silica-render -p silica-core -p silica-export
scripts/harness/check.sh
```

## Stop Gates

Stop if renderer support would require fake visual changes, broad fallback claims, divergent preview/export semantics, unsupported RAW support claims, or any possible original overwrite.
