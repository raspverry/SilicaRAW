# Task 29.2: ICC Profile Portability

## Goal

Remove required macOS ColorSync profile-file access from `silica-export` profile lookup and `silica-render` color-probe tests while preserving ICC behavior and evidence.

## Read Before Work

- [LUT and Video Service Master Plan: Phase 29](../roadmaps/lut-video-service-master-plan.md#phase-29-service-foundation-hardening)
- The accepted Task 29.0 ADR; it does not exist on this branch yet
- `docs/09_Color_Management_Specification.md`
- [Color Management](../topics/color-management.md)
- [Task 13.3 Feature-Gated Color Profile Probe](13.3-feature-gated-color-profile-probe.md)
- [Task 13.6 ICC Export Proof](13.6-icc-export-proof.md)

## Files

- `crates/silica-export/src/lib.rs`
- `crates/silica-render/src/lib.rs`

## Scope

- Dependency: Task 29.0 is not implemented on this branch. Do not start until ADR 0011 is accepted.
- Replace unconditional reads from `/System/Library/ColorSync/Profiles/` with the smallest portable sRGB and Display P3 profile-byte source.
- Prefer license-compatible repository fixtures or deterministic generated profile bytes with recorded provenance and pinned SHA-256 values.
- Keep macOS system profiles only as an optional override; neither product lookup nor tests may require them.
- Make `silica-render` color-probe tests use portable profile bytes rather than macOS-only files.
- Preserve profile classification, ICC embedding, and the `icc_profile_sha256` contract. Existing macOS profile bytes and recorded profile hashes must remain unchanged.
- Record passing `silica-export` and feature-gated `silica-render` test evidence on both Linux and macOS.
- Use only existing dependencies. Do not add or change dependencies, color transforms, export defaults, or visual color-correctness claims.

## Acceptance Criteria

- `silica-export` and `silica-render` tests do not require macOS ColorSync paths.
- Portable sRGB and Display P3 profile bytes have clear license or generation provenance and pinned hashes.
- Existing macOS ICC embedding output and recorded profile SHA-256 values are unchanged.
- `icc_profile_sha256` still hashes the exact ICC payload embedded in each export.
- Both validation commands pass on Linux and macOS with recorded platform evidence.
- No dependency or broad color-management behavior changes.

## Validation

Run on Linux and macOS:

```bash
cargo test -p silica-export
cargo test -p silica-render --features color-probe
scripts/harness/check.sh
git diff --check
```

## Stop Gates

Stop if Task 29.0 is not accepted, no license-clean or deterministic profile source can preserve the required semantics and hashes, macOS ICC evidence changes, a new dependency is required, or portability work expands into color transforms or correctness claims.
