## Goal

Add transaction-safe undo/redo command behavior for edit and culling state.

## Scope

- Add storage/core undo and redo operations for edit checkpoints and culling flags.
- Expose desktop command boundaries.
- Preserve disabled states when no undo/redo is available.
- Keep exports, backups, restores, and cache bytes out of undo mutation.

## Acceptance Criteria

- Undo/redo runs inside catalog transactions.
- Undo restores valid prior edit or culling state.
- Redo reapplies valid next edit or culling state.
- Exports are never deleted by undo.
- Original photo files are never mutated.
- Desktop command responses expose disabled/empty states cleanly.

## Validation

```bash
cargo test -p silica-storage -p silica-core -p silica-desktop

```

## Completion State

Complete. Task 16.3 adds storage/core/desktop undo and redo commands for edit checkpoints and culling flags, catalog schema version 7 history state tracking, redo invalidation after new undoable actions, disabled empty states, and tests proving export outputs remain untouched.

## Stop Gates

Stop if undo/redo can bypass transactions, delete export outputs, touch originals, or restore invalid edit graph state.
