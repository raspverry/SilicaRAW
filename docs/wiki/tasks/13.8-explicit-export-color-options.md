# Task 13.8: Explicit Export Color Options

## Goal

Enable explicit export color options only after fixture-backed color and ICC evidence exists.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Task 13.6 ICC Export Proof](13.6-icc-export-proof.md)
- [Task 13.7 Color Metadata Contract](13.7-color-metadata-contract.md)
- [UI MVP Baseline](../topics/ui-mvp-baseline.md)

## Files

- `crates/silica-export`
- `apps/desktop/static/`
- `scripts/harness/`
- `docs/wiki/topics/color-management.md`

## Scope

- Keep sRGB as the default export color target.
- Make Display P3 explicit and unavailable until proof gates pass.
- Surface unsupported combinations as disabled or blocked states.
- Keep export UI copy consistent with actual proven behavior.

## Acceptance Criteria

- Export UI/API distinguishes sRGB default from Display P3 explicit choice.
- Unsupported or unproven options cannot silently run.
- ICC behavior is tested.
- Original files remain unchanged.

## Validation

```bash
scripts/harness/check-ui-workflow-smoke.py
scripts/harness/check.sh
```

## Completion State

Complete as of 2026-06-12.

- `silica-core` exposes `export_photo_jpeg` with explicit `PhotoExportColorProfile` and keeps `export_photo_jpeg_srgb` as the default sRGB wrapper.
- The desktop command `export_photo_jpeg` treats omitted color profile as default sRGB and accepts explicit `display_p3`.
- Unsupported profile strings return `exportBlocked` instead of falling through.
- The export dialog keeps sRGB as the default and exposes Display P3 as an explicit ICC-backed choice.
- Display P3 export is still a profile/ICC capability claim, not a color-correctness claim.

Validation run:

```bash
cargo test -p silica-core -p silica-desktop
python3 scripts/harness/check-ui-workflow-smoke.py
```

## Stop Gates

Stop if proof evidence is missing, UI promises more than the backend supports, or export settings imply color correctness not yet proven.
