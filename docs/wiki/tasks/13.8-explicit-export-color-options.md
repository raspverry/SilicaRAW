## Scope

- Keep sRGB as the default export color target.
- Make Display P3 explicit and unavailable until proof gates pass.
- Surface unsupported combinations as disabled or blocked states.
- Keep export UI copy consistent with actual proven behavior.

## Acceptance Criteria

- Export UI/API distinguishes sRGB default from Display P3 explicit choice.
- Unsupported or unproven options cannot silently run.
- ICC behavior is tested.
- Original files remain unchanged.
