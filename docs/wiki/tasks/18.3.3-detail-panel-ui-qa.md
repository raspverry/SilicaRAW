# Task 18.3.3: Detail Panel UI and QA

## Goal

Expose Detail panel state in Develop without implying renderer, export, MLX denoise, or AI support that does not exist yet.

## Read Before Work

- [Task 18.3.2 Detail Preview Export Boundary](18.3.2-detail-preview-export-boundary.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [UI Visual and Responsive QA](../topics/ui-visual-responsive-qa.md)

## Files

- `apps/desktop/static/`
- `scripts/harness/check-static-ui.py`
- `scripts/harness/check-ui-workflow-smoke.py`
- `scripts/harness/run-final-visual-qa.py`

## Scope

- Add Develop Detail panel structure for sharpening/noise-reduction readback and blocked controls.
- Display disabled states for unsupported Detail preview, commit, export, and MLX denoise paths.
- Keep MLX denoise absent or visibly unavailable.
- Do not add masks, lens, geometry, or batch sync UI.

## Acceptance Criteria

- Detail panel fits current responsive Develop layouts.
- Disabled states are visible and honest.
- Static smoke covers the explicit blocked Detail state.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/check-ui-workflow-smoke.py
python3 scripts/harness/run-final-visual-qa.py
scripts/harness/check.sh
```

## Stop Gates

Stop if UI copy or controls imply MLX runtime, AI denoise, or unimplemented renderer behavior.
