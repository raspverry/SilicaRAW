## Scope

- Add a viewer QA checklist for mouse, drag, scroll, magnify, resize, Retina, external display movement, and UI responsiveness.
- Add lightweight harness checks for feature-gated build and static reserved-layout contract.
- Record screenshot viewport targets: `1280x800`, `1440x900`, and `1728x965`.
- Keep manual proof clearly separate from automated proof.

## Acceptance Criteria

- QA checklist exists and is linked from Metal Rendering.
- Harness runs without requiring the feature in default CI.
- Feature-gated checks are documented for macOS maintainers.
- Manual evidence format is clear enough for future PR review.

## Validation

```bash
scripts/harness/check.sh
```

Manual validation must be recorded when running `native-metal-viewer` on macOS.

## Completion State

Not started.

## Stop Gates

Stop if QA cannot distinguish default static UI behavior from feature-gated native viewer behavior.
