# Task 18.4.2: Geometry Preview and Export Parity

## Goal

Wire non-destructive crop, rotate, flip, and supported geometry state through preview, commit, and export.

## Read Before Work

- [Task 18.4.1 Lens Geometry Mutators](18.4.1-lens-geometry-mutators.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Data Safety](../topics/data-safety.md)

## Files

- `crates/silica-render/src/lib.rs`
- `crates/silica-core/src/lib.rs`
- `crates/silica-export/src/lib.rs`
- `apps/desktop/src-tauri/src/main.rs`

## Scope

- Implement supported non-destructive geometry preview/export semantics.
- Commit geometry edits as undoable checkpoints.
- Preserve original files and original metadata.
- Block unsupported lens profile correction or transform behavior honestly.
- Verify output dimensions and original orientation metadata non-mutation for crop/rotate paths.
- Do not add a camera/lens profile database or destructive rotate/crop operations.

## Acceptance Criteria

- Preview and export agree for supported geometry changes.
- Export cannot overwrite originals.
- Original hash checks remain unchanged.
- Source orientation metadata remains untouched.
- Unsupported lens/geometry paths are explicit.

## Validation

```bash
cargo test -p silica-render -p silica-core -p silica-export
scripts/harness/check.sh
```

## Stop Gates

Stop if any path can rotate, crop, rewrite, or overwrite the source photo.
