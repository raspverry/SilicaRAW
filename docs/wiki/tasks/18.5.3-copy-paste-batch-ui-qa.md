# Task 18.5.3: Copy Paste Batch UI and QA

## Goal

Expose copy, paste, and batch sync controls with explicit selected-photo scope and subset choice.

## Read Before Work

- [Task 18.5.2 Batch Sync History](18.5.2-batch-sync-history.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [UI Visual and Responsive QA](../topics/ui-visual-responsive-qa.md)

## Files

- `apps/desktop/static/`
- `scripts/harness/check-static-ui.py`
- `scripts/harness/check-ui-workflow-smoke.py`
- `scripts/harness/run-final-visual-qa.py`

## Scope

- Add copy/paste/sync controls to the existing Develop or selection workflow.
- Show exact selected-photo count and subset choices before batch sync.
- Keep batch scope explicit and reversible through per-photo history.
- Do not add background sync, sidecar auto-write, plugin/MCP hooks, or hidden collection-wide mutation.

## Acceptance Criteria

- UI requires explicit subset choice for batch sync.
- Disabled states cover no-photo, one-photo, unsupported-target, and invalid-selection cases.
- Static smoke covers copy/paste and batch sync happy path or honest blocked path.
- Phase 18 can be marked complete after full harness passes.

## Completion Notes

- Added a Develop inspector Copy & Sync panel with explicit selected-page scope, subset checkboxes, and separate Copy, Paste to Primary, and Batch Sync actions.
- Gated copy, paste, and batch sync to JPEG/JPG Develop photos at both UI and Core preflight boundaries.
- Kept Detail and Lens clipboard subsets disabled because those runtime paths remain unsupported or source-specific for the current alpha.
- Routed copy, plan, and apply through desktop commands backed by graph-only clipboard payloads and all-or-none batch sync history.
- Extended static UI, workflow smoke, and final visual QA coverage for selected count, subset choice, unsupported disabled states, plan rows, and honest no-runtime blocking.
