## Scope

- Add visible mask editor controls only for behavior completed in Tasks 19.1 through 19.4.
- Match existing Develop design tokens, spacing, typography, and responsive layout patterns.
- Surface unsupported AI/MLX mask modes as unavailable, not hidden successful actions.
- Extend static, workflow, and visual QA for the mask-active screen.
- Do not add AI Review, MLX model UI, plugin/MCP access, cloud features, or unrelated screens.

## Acceptance Criteria

- Mask editor controls match the design system and do not overlap at checked viewport widths.
- The M006 mask-active state is covered by visual QA.
- Active manual mask state, disabled unsupported AI/MLX options, and selected-photo scope are visible.
- Static and workflow smoke checks cover the supported happy path or an honest blocked path.
- Full harness passes before Phase 19 is marked complete.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/check-ui-workflow-smoke.py
python3 scripts/harness/run-final-visual-qa.py
```

## Completion Notes

Completed on 2026-06-16.

- Added a compact Develop inspector Mask panel for committed manual mask readback.
- Kept manual mask creation, AI masks, Subject/Sky masks, and MLX masks unavailable in the desktop UI.
- Exposed selected-photo scope, active mask row state, geometry summary, and local exposure/contrast readback.

## Stop Gates

Stop if UI can apply masks to hidden targets, imply unsupported AI/MLX behavior, or mutate originals.
