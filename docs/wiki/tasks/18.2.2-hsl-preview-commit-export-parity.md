# Task 18.2.2: HSL Preview, Commit, and Export Parity

## Goal

Wire committed HSL color mixer state through supported preview and export paths with undoable commit behavior.

## Scope

- Add supported HSL preview behavior without hidden color-space claims.
- Commit HSL edits as one undoable checkpoint.
- Ensure export applies the committed HSL state where supported.
- Record export evidence for HSL settings where current export records support it.
- Do not add color grading wheels, masks, MLX, plugin, MCP, or broad RAW claims.

## Acceptance Criteria

- Draft preview does not write catalog state.
- Commit writes validated edit state and one undoable history checkpoint.
- Export uses committed HSL state where supported.
- Unsupported paths are explicit and testable.

## Validation

```bash
cargo test -p silica-render -p silica-core -p silica-export
scripts/harness/check.sh
```

## Stop Gates

Stop if the renderer cannot honestly support preview/export parity for the selected HSL semantics.

## Completion State

- Added HSL color mixer carrier structs to render, core, export, and desktop command boundaries.

- Added HSL commit behavior through the existing validated edit graph and undoable history checkpoint path.
- Added export and histogram parity for committed HSL state in the supported JPEG/JPG and RAW-derived artifact export paths.

- Kept this limited to deterministic local pixel adjustment; no broad color-correctness or RAW renderer claim was added.
