# 25.1: Plugin Manifest Validation

## Scope

Validate plugin manifest JSON before any plugin can be enabled.

## Completed Outcome

- `silica-plugin` exposes `validate_plugin_manifest_json`.
- Valid manifests return a typed `PluginManifest`.
- Validated plugins are always `enabled_by_default = false`.
- Missing `license`, `minimum_silica_version`, or `permissions` is rejected.
- Empty permissions, duplicate permissions, unknown permissions, raw SQL, direct database access, and write-like permissions are rejected.
- `schemas/plugin_manifest.schema.json` now restricts permissions to the current safe allowlist and requires a non-empty permission array.
- No plugin runtime, executable loading, permission persistence, Core mutation path, UI, or MCP behavior was added.

## Validation

Use:

```bash
cargo test -p silica-plugin
scripts/harness/check.sh
```
