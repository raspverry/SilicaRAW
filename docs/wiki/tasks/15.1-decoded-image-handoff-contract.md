## Scope

- Add a decoded image handoff contract with dimensions, orientation, source SHA, decoder backend, input profile, working space, cache identity, pixel format, and blocked states.
- Keep render requests read-only with respect to catalog state.
- Keep image bytes out unless explicitly needed for a typed artifact boundary.
- Keep unsupported or unproven RAW classes blocked.

## Acceptance Criteria

- Contract is testable without broad RAW decoding.
- Contract can represent supported fixture-backed decode output and blocked states.
- Render does not own catalog, sidecar, export, or original-file writes.
- Cache identity is explicit and disposable.


## Completion State

Completed on 2026-06-12.

`silica-decode` now exposes a decoded image handoff contract for fixture-backed RAW evidence. The contract records source path, source SHA-256, decoder backend, status, dimensions, orientation, input profile, working space, disposable cache identity, pixel format, and message without carrying image bytes.

`silica-render` can convert a ready decoded handoff into a viewer input identity with cache key, source hash, dimensions, pixel format, decoder backend, input profile, and working space. Blocked handoffs remain decode-blocked and carry no cache identity.

`silica-core` wraps the decode and render contract as a read-only handoff plan. The wrapper records no catalog, sidecar, original, or export writes.

Next task: [Task 15.2 RAW Decode to Preview Artifact](15.2-raw-decode-preview-artifact.md).

## Stop Gates

Stop if the handoff requires broad camera support, raw extension inference, catalog writes from render, or ambiguous color/profile state.
