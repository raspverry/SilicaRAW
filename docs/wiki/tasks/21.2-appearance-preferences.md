# Task 21.2: Appearance Preferences

## Goal

Persist the supported Appearance preferences from the Phase 21 Preferences surface without moving unrelated product settings into this task.

## Read Before Work

- [Task 21.1 Preferences Information Architecture](21.1-preferences-information-architecture.md)
- [UI Mockups](../topics/ui-mockups.md)
- [Post-Alpha Product Roadmap](../roadmaps/post-alpha-product-roadmap.md#phase-21-preferences-and-app-settings)
- [Data Safety](../topics/data-safety.md)
- `MockupUI/M008_Preferences_Appearance.png`

## Status

Completed on 2026-06-17. Appearance preferences now persist in app-level desktop session state. The Preferences Appearance pane enables theme, density, and UI scale controls, applies them through existing design tokens, and exposes a reset action. The implementation does not write catalog rows, edit graph state, sidecars, originals, export defaults, cache state, MCP state, or plugin state.

## Scope

- Add app-session appearance state for theme, density, and UI scale.
- Expose desktop commands to record and reset appearance only.
- Enable the Appearance controls in the Preferences surface.
- Apply theme, density, and UI scale through tokenized CSS variables.
- Keep non-Appearance Preferences sections disabled until their scoped tasks.

## Non-Goals

- Do not add custom palettes or non-token styling.
- Do not persist Library, Cache, Color, Export, or Advanced preferences in this task.
- Do not move cache clear into Preferences.
- Do not change export defaults.
- Do not start MCP, plugin runtime, agent bridges, telemetry, cloud sync, or auto-update.

## Acceptance Criteria

- Appearance settings persist and reset through app-level session state.
- Theme, density, and UI scale controls are enabled; unrelated Preferences controls stay disabled.
- Text remains legible and unclipped in the Preferences surface.
- Design tokens remain the styling source.

## Validation

```bash
cargo test -p silica-core appearance_preferences_defaults_and_reset_are_stable
cargo test -p silica-desktop desktop_appearance_commands_round_trip_and_reset
python3 scripts/harness/check-static-ui.py
```

## Stop Gates

Stop if appearance persistence requires catalog migrations, edit graph changes, original-file access, cache mutation, export-default mutation, or enabling any unrelated Preferences section.
