# Task 29.11: Decoded Source Preview Cache

## Goal

Reuse a bounded decoded, downscaled source raster within a photo session so repeated Develop previews rerun the color chain without reopening and decoding the source file.

## Read Before Work

- [LUT and Video Service Master Plan](../roadmaps/lut-video-service-master-plan.md#task-2911-decoded-source-preview-cache)
- The accepted Task 29.0 service-direction ADR
- Task 29.10 completion record
- [Data Safety](../topics/data-safety.md)
- [Library and Cache Preferences](21.3-library-cache-preferences.md)

## Files

- `crates/silica-core/src/`

## Scope

- Dependency gate: Task 29.0 is not implemented on this branch. Do not start implementation until Task 29.0 is accepted and Task 29.10 is complete.
- Add a photo-session-local in-memory cache for the decoded, downscaled source raster used by Develop preview.
- Key entries by photo ID plus the existing source fingerprint contract; never reuse an entry after the source fingerprint changes.
- Cache only the reusable source raster. Draft adjustments must continue to rerun the color chain.
- Enforce and document an exact hard byte bound, including byte accounting and eviction behavior; the cache must never become durable recovery state.
- Make the existing cache-clear command clear this in-memory cache as well as its current disposable disk caches.
- Add a narrow test seam that counts source opens or decode entry calls without changing production behavior.
- Use only existing workspace dependencies. Do not add background work, persistence, or a second cache subsystem.

## Acceptance Criteria

- Repeated previews for the same photo ID and source fingerprint reuse the decoded raster and do not reopen the source file, as proven through the test seam.
- A changed source fingerprint invalidates the stale entry and forces the source to be opened and decoded again.
- Cache clear removes all decoded source entries, and the next preview reopens the source.
- Tests prove accounted cache memory never exceeds the documented hard byte bound and that eviction preserves correct preview behavior.
- Cached data remains session-local and disposable.
- Original source hashes remain unchanged across cache hit, invalidation, eviction, and clear paths.

## Validation

```bash
cargo test -p silica-core
scripts/harness/check.sh
```

## Stop Gates

Stop if Task 29.0 is not accepted, Task 29.10 is incomplete, source identity cannot be validated before reuse, the cache can exceed its documented bound, cache clear cannot guarantee removal, a new dependency is required, or any path could mutate an original file.
