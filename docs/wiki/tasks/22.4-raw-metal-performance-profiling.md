# 22.4: RAW and Metal Performance Profiling

## Goal

Record local RAW/Metal-adjacent performance evidence without expanding RAW decoding, native Metal viewer behavior, or installed-app instrumentation.

## Scope

- Add a local profile runner and report for decode, render, UI-latency, and export timing categories.
- Keep the profile evidence local-machine only and non-generalized.
- Record memory pressure context for each measured command.
- Keep fixture-backed RAW decode/export and full Metal pixel rendering explicitly gated when legal fixture assets or installed-app instrumentation are missing.

## Non-Goals

- Do not implement broad RAW decoding.
- Do not implement product Metal pixel rendering.
- Do not add dependencies, telemetry, or background profiling.
- Do not infer full interactive UI latency from cargo test timing.
- Do not commit legal RAW fixture assets or private user photos.

## Validation

```bash
python3 scripts/harness/run-raw-metal-profile.py
python3 scripts/harness/check-raw-metal-profile.py
scripts/harness/check.sh
```

## Result

Completed on 2026-06-17. The profile report separates decode, render, UI-latency, and export categories, records median/p95 timing plus child-process max RSS, and documents unsupported or gated paths instead of hiding them. The measured rows are contract or feature-gated smoke paths; full fixture-backed RAW decode/export timing and full installed-app interactive Metal profiling remain future evidence tasks.
