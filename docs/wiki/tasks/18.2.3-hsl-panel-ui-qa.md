# Task 18.2.3: HSL Panel UI and QA

## Goal

Expose HSL color mixer controls in Develop with compact, consistent, responsive UI.

## Scope

- Add HSL panel controls for the schema-owned color mixer channels.
- Preserve existing Develop typography, spacing, tabs/panels, and responsive behavior.
- Keep unsupported states visible.
- Do not add color grading wheels, masks, or batch sync UI.

## Acceptance Criteria

- HSL controls fit compact, desktop, and wide layouts.
- UI labels and controls remain consistent with existing Develop sections.
- Static smoke covers the HSL interaction path.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/check-ui-workflow-smoke.py
```

## Completion State

- Added a compact Develop HSL Mixer panel for the eight schema-owned channels: red, orange, yellow, green, aqua, blue, purple, and magenta.
- Wired per-channel hue, saturation, and luminance controls to `preview_hsl_color_mixer_edit` and `commit_hsl_color_mixer_edit`.
- Kept HSL draft preview non-persistent and followed the existing one-family-at-a-time commit pattern.
- Extended static UI smoke, workflow smoke, and final visual QA checks for HSL control bounds, command wiring, support state, and seeded blue-channel UI state.

## Stop Gates

Stop if the panel creates overlap, inconsistent design tokens, or unsupported-success claims.
