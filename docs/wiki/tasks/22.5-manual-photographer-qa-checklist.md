# 22.5: Manual Photographer QA Checklist

## Goal

Add a real photographer-facing manual QA checklist for the local macOS alpha workflow while keeping private or unlicensed media out of the repository.

## Scope

- Cover culling, metadata, undo, Develop controls, masks, export, responsiveness, data safety, and color/export checks.
- Require licensed or user-provided local assets for manual runs.
- Keep RAW fixture validation gated by `SILICARAW_RAW_FIXTURE_MANIFEST`.
- Record known limitations instead of expanding product claims.

## Non-Goals

- Do not add test media, private photos, or unlicensed fixture assets.
- Do not implement UI screens or product behavior.
- Do not claim clean-Mac DMG install QA completion.
- Do not add broad RAW, MLX, MCP, plugin, cloud, telemetry, or auto-update behavior.

## Validation

```bash
python3 scripts/harness/check-photographer-qa-checklist.py
python3 scripts/harness/check-md-links.py
scripts/harness/check.sh
```

## Evidence

- [Photographer Workflow QA](../../../checklists/PHOTOGRAPHER_WORKFLOW_QA.md)

## Known limitations

The checklist is a manual QA record, not proof of clean-Mac DMG install QA, full RAW fixture coverage, native Metal pixel throughput, MLX, MCP, plugins, cloud sync, telemetry, or auto-update behavior.

## Result

Completed on 2026-06-17. The checklist defines manual workflow evidence for licensed or user-provided local assets across culling, metadata, undo, Develop, masks, export, responsiveness, data safety, color/export, and known limitations. The harness now verifies that the checklist exists, covers the required workflow sections, and keeps private media and broad unsupported feature claims out of scope.
