## Scope

- Add visible draft behavior for vibrance/saturation where support is honest.
- Commit one undoable checkpoint for color presence changes.
- Ensure export uses committed vibrance/saturation state.
- Keep unsupported states explicit.
- Do not add histogram, presets, color correctness claims, or broad RAW claims.

## Acceptance Criteria

- Draft preview does not write catalog state.
- Commit writes validated edit state and one undoable history checkpoint.
- Export applies committed vibrance/saturation state where supported.
- Unsupported or blocked sources remain honest.
- Sidecar status follows Phase 16 rules.

## Validation

```bash
cargo test -p silica-render -p silica-core -p silica-export
scripts/harness/check.sh
```

## Completion State

Complete.

- Render requests now carry vibrance and saturation for preview/export planning.
- JPEG/JPG Develop preview and JPEG export apply the same deterministic local color presence adjustment from the validated edit graph.
- Core exposes preview/commit commands for color presence; draft preview does not write active edit state or history.
- Color presence commit writes one undoable history checkpoint labelled `Color presence`.
- Export records `vibrance` and `saturation` in export settings for raster and RAW-derived export paths.
- Desktop command responses and static Develop controls expose color presence without adding histogram, presets, broad RAW support, or broad color-correctness claims.

## Stop Gates

Stop if the implementation claims color correctness beyond existing fixture evidence.
