# Task 21.4: Color and Export Defaults

## Goal

Move supported Color and Export default controls into the Phase 21 Preferences surface by reusing the catalog-owned export settings model from Task 20.1.

## Status

Completed on 2026-06-17. Preferences now expose supported Color default space and Export default format/quality controls for the active local library. The controls reuse `get_export_settings` and `save_export_settings`; they do not create a second preferences store. The Export dialog and Preferences panes share the same default state. JPEG sRGB 90 remains the conservative default, Display P3 remains explicit and JPEG-only, and PNG/TIFF defaults are forced to sRGB.

## Scope

- Enable Preferences Color default space for supported export defaults.
- Enable Preferences Export default format and quality controls.
- Persist defaults through the existing catalog-owned export settings path.
- Keep validation at the existing storage/core/desktop command boundary.
- Keep unsupported combinations, such as PNG/TIFF with Display P3, blocked before save.
- Keep Preferences Profile Policy disabled until a scoped task owns profile-policy behavior.

## Non-Goals

- Do not add a second app-session export preference model.
- Do not change the edit graph, sidecar schema, or develop edit state.
- Do not change export pixel rendering or add new file formats.
- Do not make Display P3 the default.
- Do not enable Advanced agent, MCP, or plugin controls.
- Do not mutate original photo files.

## Acceptance Criteria

- Defaults are validated against supported formats and color profiles.
- Unsupported defaults cannot be saved from Preferences.
- Export dialog reflects current defaults after Preferences changes.
- Preferences changes do not write edit history, sidecars, export outputs, or original files.
- Color/Export controls have clear disabled states when no library is active.

## Stop Gates

Stop if this task requires a catalog migration, a new dependency, edit graph schema changes, original-file access, a second preferences store, silent Display P3 defaults, or enabling advanced agent/plugin/MCP runtime.
