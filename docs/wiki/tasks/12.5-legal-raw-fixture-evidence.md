# Task 12.5: Legal RAW Fixture Evidence

## Goal

Run the existing Core Image RAW probe against legally usable RAW fixtures and update the support matrix from evidence.

## Read Before Work

- [Phase 12 RAW Proof Plan](../roadmaps/phase-12-raw-proof-plan.md)
- [Phase 12 RAW Proof Brief](../phases/phase-12-raw-proof.md)
- [RAW Decoding](../topics/raw-decoding.md)
- [Fixture Manifest Schema](../../../schemas/fixture_manifest.schema.json)

## Files

- `docs/wiki/topics/raw-decoding.md`
- `docs/wiki/log.md`
- Ignored local fixture media under `.tmp/` or another ignored local path
- Ignored local manifest supplied through `SILICARAW_RAW_FIXTURE_MANIFEST`

## Scope

- Review candidate fixture source licenses and provenance.
- Keep fixture media and local manifests out of git.
- Run `scripts/harness/check-raw-probe-fixtures.py` with a legal local manifest.
- Update the RAW support matrix from actual probe evidence.

## Non-Goals

- Do not commit RAW media.
- Do not use unclear-license samples.
- Do not display RAW pixels in the product UI.
- Do not add LibRaw unless the matrix records a concrete Core Image gap first.
- Do not mutate originals.

## Acceptance Criteria

- Every used fixture has source, license, privacy, SHA-256, and fixture class recorded.
- The local manifest validates against the fixture manifest schema.
- Probe results record success or failure with backend, platform, source hash, dimensions, orientation, error category, and original hash preservation.
- The support matrix changes only from recorded evidence.
- Any product API support change after successful evidence is split into a separate atomic task.

## Stop Gates

Stop if a fixture license is unclear, a source hash cannot be recorded, the manifest requires unsafe paths, or the probe cannot prove original hash preservation.

## Notes for LLM Agents

This task is the evidence gate. It does not make RAW decoding a product feature by itself.
