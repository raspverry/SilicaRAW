# 24.4: First Non-Mutating AI Review Feature

## Scope

Add the first AI review feature as review information only, using blur review as the initial task type.

## Completed Outcome

- `silica-core` exposes `get_ai_review_panel` for stored local blur review results.
- The panel returns a model-unavailable state when no stored result exists, while the editor remains usable.
- AI review items are read from `ai_results`; no inference or model loading was added.
- Desktop exposes a read-only `get_ai_review_panel` command.
- The static app adds an AI Review surface based on `MockupUI/M010_AI_Review.png`.
- Approval is visibly deferred and disabled until Task 24.5.
- The surface states that review output does not write edits, flags, or originals.
- Visual QA includes `M023-ai-review`.

## Verification

Use:

```bash
cargo test -p silica-core ai_blur_review_panel
cargo test -p silica-mlx records_task_24_4
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml desktop_command_returns_ai_review_panel_without_mutating_edits
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/run-final-visual-qa.py
scripts/harness/check.sh
```

## Next Task

Task 24.5 should add explicit AI suggestion approval. Approval must convert suggestions into edit graph or mask data only through an explicit user action and an undoable checkpoint.
