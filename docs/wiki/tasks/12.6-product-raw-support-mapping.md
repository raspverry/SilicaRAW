# Task 12.6: Product RAW Support Mapping

## Goal

Map fixture-backed Core Image probe evidence into the product RAW decode API without displaying RAW pixels.

## Read Before Work

- [Phase 12 RAW Proof Brief](../phases/phase-12-raw-proof.md)
- [RAW Decoding](../topics/raw-decoding.md)
- [Task 12.5 Legal RAW Fixture Evidence](12.5-legal-raw-fixture-evidence.md)
- [Architecture Patch](../../20_v1_1_Architecture_Patch.md)

## Files

- `crates/silica-decode`
- `crates/silica-core`
- Relevant docs if API behavior changes

## Scope

- Keep arbitrary path-based RAW candidates blocked unless they are backed by probe evidence.
- Add an evidence-driven API path that accepts a fixture class and `RawProbeResult`.
- Return `Supported` only when fixture classes A-D have successful macOS Core Image probe results with source hashes and dimensions.
- Return explicit blocked states for failed probes, missing dimensions, unsupported classes, and non-success statuses.
- Do not route decoded pixels to render, UI, export, cache, or catalog layers.

## Acceptance Criteria

- Fixture-proven classes A-D can produce metadata-only `Supported` plans from successful probe results.
- Class E and unknown classes remain blocked.
- Existing `plan_product_raw_decode(path)` remains conservative and does not infer support from file extension alone.
- No original file mutation, UI RAW display, export expansion, cache generation, color correctness claim, broad camera support claim, or LibRaw dependency is added.

## Validation

```bash
cargo test -p silica-decode -p silica-core
scripts/harness/check.sh
```

## Completion State

Completed on 2026-06-12.

`silica-decode` now exposes `plan_product_raw_decode_from_probe`, and `silica-core` wraps it. The existing path-only `plan_product_raw_decode` remains conservative and keeps arbitrary RAW candidates blocked.

Successful macOS Core Image probe results for fixture classes A-D can return metadata-only `Supported` plans with backend, dimensions, and orientation when source hash evidence is present. Class E, unknown classes, failed probes, incomplete probes, and successful probes missing dimensions remain blocked.

No UI RAW display, export expansion, cache generation, color correctness claim, broad camera support claim, original mutation, or LibRaw dependency was added.

## Stop Gates

Stop if the implementation needs committed RAW media, decoded pixels, render/export behavior, or a new decoder dependency.

## Notes for LLM Agents

This is a metadata support-plan task only. The next phase still has to prove color and pixel behavior before RAW preview/export claims are expanded.
