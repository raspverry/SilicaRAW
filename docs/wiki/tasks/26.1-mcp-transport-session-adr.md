# 26.1: MCP Transport and Session ADR

## Scope

Decide MCP transport, session lifetime, permission posture, and default disabled state.

## Completed Outcome

- [ADR 0010](../decisions/adr-0010-mcp-transport-session.md) selects disabled-by-default stdio-first MCP.
- One MCP session is one local stdio server process lifetime.
- No background listener, persisted token, persisted grant, app-start server, or HTTP transport is added.
- First MCP mode remains read-only only.
- Mutating tools, permission self-escalation, direct SQLite, unrestricted filesystem, original mutation, plugin install, and plugin enable are out of scope.
- Future HTTP transport requires a separate ADR.
