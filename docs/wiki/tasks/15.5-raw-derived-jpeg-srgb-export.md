# Task 15.5: RAW-Derived JPEG sRGB Export

## Goal

Export fixture-backed RAW-derived JPEG sRGB with ICC evidence from the full-resolution export path.

## Read Before Work

- [Task 15.4 Exposure Contrast Metal Draft Path](15.4-exposure-contrast-metal-draft-path.md)
- [Phase 15 RAW Color Metal Vertical Slice Brief](../phases/phase-15-raw-color-metal-vertical-slice.md)
- [Color Management](../topics/color-management.md)

- `crates/silica-export/src/lib.rs`
- `crates/silica-core/src/lib.rs`
- `crates/silica-decode/src/lib.rs`
- `crates/silica-render/src/lib.rs`
- `apps/desktop/src-tauri/src/main.rs`
- `checklists/`

## Scope

- Export from the full-resolution RAW-derived path, not the preview texture cache.
- Embed sRGB ICC.
- Record output SHA-256, source SHA-256, ICC embedded state, ICC profile SHA-256, decoder backend, and profile metadata.
- Keep output path separate from original source path.

## Acceptance Criteria

- RAW-derived JPEG sRGB export is fixture-backed.
- sRGB ICC is embedded and inspectable.
- Output/source/ICC hashes are recorded.
- Export cannot overwrite original RAW source.
- Viewer texture cache is not the export source.

## Validation

```bash
cargo test -p silica-export -p silica-core -p silica-decode -p silica-render
scripts/harness/check.sh
```

Manual or harness inspection must record ICC evidence.

## Completion State

Not started.

## Stop Gates

Stop if missing or unsupported profile data silently exports, output can overwrite the original, or export depends on viewer texture cache.
