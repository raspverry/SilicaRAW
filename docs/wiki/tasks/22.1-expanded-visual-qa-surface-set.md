# 22.1: Expanded Visual QA Surface Set

## Goal

Expand final visual/responsive QA so the larger post-alpha editor is checked as a coherent product surface, not only the original Library, Develop, and Export MVP path.

## Scope

- Add explicit visual QA surfaces for Library filters, Library metadata, Develop history, expanded Develop panels, Mask Editor, Preferences, and expanded Export workflow state.
- Keep the existing compact, desktop, and large desktop viewport set.
- Keep the runner dependency-free and Chrome/CDP based.

## Acceptance

- Final visual QA checks all expanded surfaces at `1280x800`, `1440x900`, and `1728x965`.
- DOM metrics fail on horizontal overflow, toolbar overlap, clipped controls, missing seeded surface state, or dialog viewport overflow.
- No new product feature, runtime fallback, RAW decode, Metal viewer, MLX, MCP, plugin runtime, or dependency is introduced.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/run-final-visual-qa.py
scripts/harness/check.sh
```

## Result

Completed on 2026-06-17. The final visual QA runner now checks 22 surfaces across 3 viewport widths, producing 66 screenshots and a structured result file under `.tmp/final-visual-responsive-qa/`.
