# Task 15.2: RAW Decode to Preview Artifact

## Goal

Create bounded disposable preview artifacts for fixture-backed RAW files.

- `crates/silica-render/src/lib.rs`
- `scripts/harness/`
- `checklists/`

## Scope

- Use Core Image for fixture-backed RAW preview artifact creation on macOS.
- Store preview artifacts under bounded disposable library cache paths.
- Keep unsupported RAWs blocked and reviewable.
- Preserve original RAW file hashes.
- Keep preview artifact generation separate from full-resolution export.

## Acceptance Criteria

- RAW Class A fixture path can produce a bounded disposable preview artifact.
- RAW Class C or D coverage is included when fixture evidence exists.
- Unsupported or unproven RAW classes remain blocked.
- Preview artifact output cannot target original source paths.
- Original hashes are verified unchanged.

## Validation

```bash
cargo test -p silica-decode -p silica-core -p silica-storage -p silica-render
scripts/harness/check.sh
```

Fixture-backed validation must use a legal local RAW fixture manifest when required.

## Completion State

Completed on 2026-06-12.

Task 15.2 added:

- `silica-decode::write_raw_preview_artifact` for feature-gated Core Image JPEG sRGB RAW preview artifact writing.
- Source/output canonical overwrite rejection.
- Stale probe source SHA rejection before artifact write.
- Unsupported or unproven fixture class blocked state with no artifact path or byte count.
- Bounded preview dimensions and `JpegSrgb8` handoff identity for preview artifacts.
- `silica-core::write_raw_preview_artifact_for_probe` to construct product preview paths under library `previews/` and record preview cache metadata only after successful writes.
- `silica-storage` preview/thumbnail cache path validation using canonical paths, including `..` escape rejection.
- `silica-render` mapping for JPEG sRGB decoded preview artifact identity.

Fixture-backed local validation wrote RAW preview artifacts for Class A and Class C or D evidence and verified original hashes stayed unchanged.

Next task: [Task 15.3 Metal Preview Display](15.3-metal-preview-display.md).

## Stop Gates

Stop if preview generation can write outside disposable library cache paths, mutates originals, or treats extension-only RAWs as supported.
