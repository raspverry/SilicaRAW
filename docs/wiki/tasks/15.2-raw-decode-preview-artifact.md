# Task 15.2: RAW Decode to Preview Artifact

## Goal

Create bounded disposable preview artifacts for fixture-backed RAW files.

- `crates/silica-core/src/lib.rs`
- `crates/silica-storage/src/lib.rs`
- `crates/silica-render/src/lib.rs`
- `scripts/harness/`
- `checklists/`

## Scope

- Use Core Image for fixture-backed RAW preview artifact creation on macOS.
- Store preview artifacts under bounded disposable library cache paths.
- Keep unsupported RAWs blocked and reviewable.
- Preserve original RAW file hashes.
- Keep preview artifact generation separate from full-resolution export.

## Acceptance Criteria

- RAW Class A fixture path can produce a bounded disposable preview artifact.
- RAW Class C or D coverage is included when fixture evidence exists.
- Unsupported or unproven RAW classes remain blocked.
- Preview artifact output cannot target original source paths.
- Original hashes are verified unchanged.

## Validation

```bash
cargo test -p silica-decode -p silica-core -p silica-storage -p silica-render
scripts/harness/check.sh
```

Fixture-backed validation must use a legal local RAW fixture manifest when required.

## Completion State

Not started.

## Stop Gates

Stop if preview generation can write outside disposable library cache paths, mutates originals, or treats extension-only RAWs as supported.
