# Task 14.3: Reserved Viewer Layout Handshake

## Goal

Connect the web shell and native bridge through an explicit viewer host rectangle without covering arbitrary UI.

## Read Before Work

- [Task 14.1 AppKit/Metal Viewer Bridge Contract](14.1-appkit-metal-viewer-bridge-contract.md)
- [Task 14.2 Native Viewer Feature Gate](14.2-native-viewer-feature-gate.md)
- [UI MVP Baseline](../topics/ui-mvp-baseline.md)

- `apps/desktop/static/index.html`

- `scripts/harness/check-ui-workflow-smoke.py`
- `docs/wiki/topics/metal-rendering.md`

## Scope

- Add stable viewer host markers or geometry reporting for Loupe/Develop viewer surfaces.
- Keep web controls outside the native viewer rectangle.
- Make native viewer unavailable or inert when the feature is off.
- Add static checks that prevent regressing into arbitrary overlay behavior.

## Acceptance Criteria

- Native viewer host geometry is explicit and testable.
- Toolbar, inspector, sidebars, filmstrip, and export dialog are not hidden by native viewer ownership.
- Feature-off UI remains functional with the current raster preview path.
- Static harness checks the reserved host contract.

## Validation

```bash
python3 scripts/harness/check-ui-workflow-smoke.py
cargo test -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

## Completion State

Completed on 2026-06-12.

Task 14.3 added:

- reserved native viewer host markers for `#loupeViewer` and `#developPreviewSurface`
- inert feature-off geometry reporting through `window.SilicaRAWViewerHost`
- explicit logical rectangle, backing scale, drawable size, surface identity, and web-fallback state reporting
- static UI harness checks that reserved native viewer hosts are exactly Loupe and Develop and that controls stay outside those hosts
- native module contract fields for reserved surfaces and web-host geometry consumption

No AppKit view installation, Metal rendering, texture cache, shader passes, RAW pixels, or native input ownership was added.

## Stop Gates

Stop if the only feasible route is a native overlay that can cover controls or text without a reserved layout contract.
