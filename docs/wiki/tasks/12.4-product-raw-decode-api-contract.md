# Task 12.4: Product RAW Decode API Contract

## Goal

Define the product RAW decode API for supported RAW fixture classes after Core Image support evidence exists.

## Read Before Work

- [Phase 12 RAW Proof Brief](../phases/phase-12-raw-proof.md)
- [RAW Decoding](../topics/raw-decoding.md)
- Task 12.3 support matrix
- [Architecture Patch](../../20_v1_1_Architecture_Patch.md)

## Files

- `crates/silica-decode`
- `crates/silica-core`
- Relevant docs if API behavior changes

## Scope

- Return decoded metadata, dimensions, orientation, decoder backend, and explicit blocked states.
- Keep decoder-specific decisions inside decode/core boundaries.
- Keep render and catalog layers free of decoder-specific policy.
- Keep unsupported RAWs as clear blocked states.

## Acceptance Criteria

- Supported fixture classes have an API contract backed by Task 12.3 evidence.
- Unsupported RAWs remain explicit blocked states.
- No UI RAW pixel display is wired in this task.
- Original files remain unchanged.

## Validation

```bash
cargo test -p silica-decode -p silica-core
scripts/harness/check.sh
```

## Stop Gates

Stop if Task 12.3 has not established supported fixture classes. Do not design broad RAW behavior from assumptions.

## Notes for LLM Agents

This task defines API contracts only. UI rendering, Metal viewer integration, color correctness, and export expansion belong to later phases.
