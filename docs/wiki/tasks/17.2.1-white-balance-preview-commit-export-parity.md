# Task 17.2.1: White Balance Preview, Commit, and Export Parity

## Goal

Wire the white-balance family through draft preview, committed edit state, undo/history, and export semantics.

## Scope

- Add visible draft behavior for supported JPEG/JPG and supported fixture-backed RAW paths where the renderer can honestly support it.
- Commit one undoable checkpoint for white-balance changes.
- Ensure export uses committed white-balance state.
- Keep unsupported states explicit.
- Do not add tone recovery, vibrance/saturation, histogram, presets, or broad RAW claims.

## Acceptance Criteria

- Draft preview does not write catalog state.
- Commit writes validated edit state and one undoable history checkpoint.
- Export applies the committed white-balance state where supported.
- Unsupported or blocked sources remain honest.
- Sidecar status follows Phase 16 rules.

## Stop Gates
