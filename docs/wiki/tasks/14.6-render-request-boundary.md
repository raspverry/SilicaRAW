# Task 14.6: Render Request Boundary

## Goal

Define the typed preview render request boundary between `silica-render` and the native viewer bridge.

## Read Before Work

- [Task 14.1 AppKit/Metal Viewer Bridge Contract](14.1-appkit-metal-viewer-bridge-contract.md)
- [Task 14.4 Resize Retina Lifecycle Proof](14.4-resize-retina-lifecycle-proof.md)
- [Metal Render Pipeline Specification](../../08_Metal_Render_Pipeline_Specification.md)

## Files

- `crates/silica-render/src/lib.rs`
- `apps/desktop/src-tauri/src/native_metal_viewer.rs`
- `docs/wiki/topics/metal-rendering.md`

## Scope

- Add a typed render request contract for viewer preview work.
- Record latest-request-wins behavior for interaction.
- Keep render requests read-only with respect to catalog state.
- Keep image pixels out unless the task has explicit Phase 15 scope.

## Acceptance Criteria

- Render request contract is testable without a real image texture.
- Latest request wins behavior is documented and unit-tested where possible.
- No catalog writes occur from render request creation or viewer scheduling.
- The contract can carry future decoded/raster texture inputs without committing Phase 15 behavior.

## Validation

```bash
cargo test -p silica-render
cargo test -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

## Completion State

Not started.

## Stop Gates

Stop if the boundary requires RAW decoding, color transform output, or shader pass implementation in this phase.
