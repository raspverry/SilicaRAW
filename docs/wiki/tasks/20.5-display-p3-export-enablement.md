# Task 20.5: Display P3 Export Enablement

## Goal

Close Phase 20 by verifying that Display P3 export is enabled only as an explicit JPEG profile/ICC capability, not as a broad visual color-correctness claim.

## Status

Completed on 2026-06-17. Display P3 export was already implemented through the Task 13.6 ICC-backed JPEG export path and surfaced by Task 13.8 as an explicit UI/API choice. Task 20.5 records that Phase 20 keeps this enablement bounded: JPEG only, explicit selection only, embedded ICC evidence required, and no visual color-correctness claim.

## Existing Evidence

- `silica-export` tests prove explicit Display P3 JPEG export embeds an inspectable ICC profile and leaves originals unchanged.
- `silica-core` and desktop tests prove omitted color profile remains sRGB and explicit `display_p3` routes through the command boundary.
- The export UI keeps sRGB as default and marks Display P3 as explicit ICC-backed selection.
- PNG/TIFF remain sRGB-only in this alpha until a separate color-managed proof exists.
- Manual visual QA remains documented, not claimed as executed for broad color correctness.

## Scope

- Confirm Display P3 is enabled only for explicit JPEG export.
- Keep sRGB as the default export target.
- Keep PNG/TIFF Display P3 blocked until color-managed proof exists.
- Update the color QA checklist to cover Phase 20 Display P3 enablement language.
- Add harness coverage that prevents stale docs from claiming Display P3 is not user-facing or visually proven.

## Non-Goals

- Do not add Display P3 PNG/TIFF export.
- Do not add broad color correctness, camera-profile, or RAW color claims.
- Do not add new fixtures, dependencies, or ColorSync transforms.
- Do not add MLX, MCP, plugin runtime, cloud sync, telemetry, auto-update, Homebrew, or Mac App Store behavior.

## Acceptance Criteria

- P3 export embeds expected ICC evidence through existing tests.
- UI distinguishes sRGB default from Display P3 explicit choice.
- Color QA checklist says Display P3 export remains explicit and is a profile/ICC capability claim only.
- Stale docs no longer say Display P3 is not wired to a user-facing option.

## Stop Gates

Stop if Display P3 enablement requires PNG/TIFF expansion, if ICC inspection fails, if UI makes Display P3 the default, or if docs imply visual color correctness.
