# Task 17.4: Reset, Before/After, and Basic Presets

## Goal

Add reset actions, before/after view behavior, and built-in basic presets for the P0 Develop baseline.

## Scope

- Add validated reset behavior for P0 basic controls.
- Add before/after as view-only state.
- Add built-in basic presets using validated edit graph changes.
- Keep preset/reset commits undoable.
- Do not add user preset storage, batch sync, or cloud/plugin preset behavior.

## Acceptance Criteria

- Reset and preset apply create undoable checkpoints.
- Before/after creates no edit history by itself.
- Built-in presets validate and round-trip through the edit graph.
- Sidecar status follows Phase 16 rules after committed changes.

## Validation

```bash
cargo test -p silica-edit -p silica-core
scripts/harness/check.sh
```

## Completion State

Complete.

- `silica-edit` defines built-in P0 Basic presets and reset helpers that validate and round-trip through the edit graph schema.
- `silica-core` commits reset and preset application as one full-graph undoable edit checkpoint through the existing storage transaction path.
- Desktop exposes reset/preset commands using the existing `EditCommit` response contract.
- Static Develop UI has view-only Before/After controls, a Reset All action, and active built-in preset rows.
- Before/After uses local UI state only and does not call mutation commands or write history.

## Stop Gates

Stop if before/after mutates catalog state or presets bypass edit graph validation.
