# Task 21.1: Preferences Information Architecture

## Goal

Create the compact preferences surface that later Phase 21 tasks can fill in without scattering settings across unrelated UI panels.

## Read Before Work

- [UI Mockups](../topics/ui-mockups.md)
- [Post-Alpha Product Roadmap](../roadmaps/post-alpha-product-roadmap.md#phase-21-preferences-and-app-settings)
- [UI MVP Baseline](../topics/ui-mvp-baseline.md)
- `MockupUI/M008_Preferences_Appearance.png`

## Status

Completed on 2026-06-17. The desktop shell now exposes a compact Preferences dialog from the toolbar and welcome screen. It defines the Phase 21 sections: Appearance, Library, Cache, Color, Export, and Advanced. Section navigation is live, but every unimplemented setting remains disabled.

## Scope

- Add a discoverable Preferences entry point.
- Add a compact dialog with a left section list and right content pane.
- Define Appearance, Library, Cache, Color, Export, and Advanced sections.
- Keep Advanced agent access, MCP tools, and plugin runtime off by default.
- Keep future setting controls disabled until their scoped implementation tasks.

## Non-Goals

- Do not persist preferences in this task.
- Do not move cache-clear behavior into Preferences until Task 21.3.
- Do not change export defaults until Task 21.4.
- Do not start MCP, plugin runtime, agent bridges, telemetry, cloud sync, or auto-update.

## Acceptance Criteria

- Preferences are discoverable from the main toolbar and welcome screen.
- The surface remains compact and follows the M008 information-architecture target.
- Advanced agent access remains disabled and unchecked by default.
- No unimplemented setting appears enabled.

## Validation

```bash
python3 scripts/harness/check-static-ui.py
python3 scripts/harness/check-ui-workflow-smoke.py
scripts/harness/check.sh
```

## Stop Gates

Stop if implementing this task requires preference persistence, backend commands, cache mutation, export-default mutation, MCP/plugin runtime, or any enabled control without its scoped implementation task.
