## Scope

- Record reserved native viewer layout rules.
- Record AppKit lifecycle ownership.
- Record event ownership between web UI and native viewer.
- Record render request and texture lifecycle boundaries at a contract level.
- Record stop conditions that trigger fallback planning.

## Acceptance Criteria

- Contract explicitly continues Spike 001 Path B.
- Native viewer region is reserved, not overlaid on arbitrary web UI.
- Failure conditions preserve the SwiftUI/AppKit fallback rule.
- Open questions are updated or narrowed rather than silently assumed.
- No code implementation is added.
