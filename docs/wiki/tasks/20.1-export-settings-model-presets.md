# Task 20.1: Export Settings Model and Presets

## Goal

Add a persistent export settings model and conservative export presets without mixing export preferences into the edit graph.

## Read Before Work

- [Post-Alpha Product Roadmap: Phase 20](../roadmaps/post-alpha-product-roadmap.md#phase-20-export-and-delivery-expansion)
- [Phase 19 Manual Masks](../phases/phase-19-manual-masks.md)
- [Edit Graph](../topics/edit-graph.md)
- [Data Safety](../topics/data-safety.md)
- `docs/19_Schema_Reference.md`
- `docs/DEPENDENCIES.md` if adding or changing a dependency

## Files

- `crates/silica-export/`
- `crates/silica-storage/`
- `crates/silica-core/`
- `apps/desktop/static/`
- `scripts/harness/`

## Scope

- Define export settings as export-owned state, separate from edit graph state.
- Persist default export settings and named presets in catalog-owned storage.
- Keep JPEG sRGB as the conservative default.
- Surface preset/default state in the existing export UI without adding unrelated screens.
- Preserve original-file overwrite protection and explicit output path safety.

## Non-Goals

- Do not add PNG or TIFF export.
- Do not add batch export progress or recent exports.
- Do not add metadata policy controls beyond the settings shape needed for this task.
- Do not broaden RAW support or color-management claims.
- Do not add auto-update, cloud sync, plugin/MCP, telemetry, or MLX behavior.

## Acceptance Criteria

- [x] Export settings do not modify develop edits or edit graph history.
- [x] Presets are persisted, editable through the intended local-alpha path, and reloadable.
- [x] Defaults remain conservative and compatible with current JPEG sRGB export.
- [x] UI shows current export settings and preset state honestly.
- [x] Tests prove original files are unchanged and unsafe output paths remain blocked.

## Implementation Status

Completed on 2026-06-17.

- Catalog schema version 9 adds `export_presets` and `export_settings`.
- The seeded default is `JPEG sRGB 90`.
- Storage/Core/Desktop expose read, save-default, and save-preset paths.
- The existing Export dialog shows preset selection, editable preset naming, and current default state.
- Export preference changes remain separate from edit graph history and original/export output file writes.

## Validation

## Stop Gates

Stop if export settings require edit graph schema changes, if settings can overwrite originals, or if UI implies unsupported PNG/TIFF/batch/metadata behavior.
