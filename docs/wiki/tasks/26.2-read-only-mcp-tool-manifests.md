# 26.2: Read-Only MCP Tool Manifests

## Scope

Define the first MCP tool manifest contract. This task is schema and validation only.

## Completed Outcome

- `schemas/mcp_tool_manifest.schema.json` now describes `silica.mcp_tool` v1.
- `crates/silica-mcp` validates read-only tool manifests with stable `mcp:read_only` permission IDs.
- Allowed read-only tool IDs are:
  - `silica.photos.list`
  - `silica.photos.get`
  - `silica.photos.get_metadata`
  - `silica.collections.list`
  - `silica.selection.get`
  - `silica.presets.list`
  - `silica.exports.list`
- Valid manifests require:
  - `requires_confirmation: false`
  - `side_effects: []`
  - `undoable: false`
  - object-shaped input and output schemas
- Mutating tool IDs, non-read-only permissions, side effects, unknown fields, and direct SQLite claims are rejected.

## Non-Goals

- No MCP server.
- No MCP adapter runtime.
- No stdio process launch.
- No Core API read implementation.
- No direct SQLite access.
- No mutating MCP tools.
- No permission self-escalation.

## Validation

Use:

```bash
cargo test -p silica-mcp
scripts/harness/check.sh
```
