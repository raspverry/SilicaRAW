# 24.3: AI Result Store and Read Path

## Scope

Store AI output separately from edit graph and catalog flags, then expose a read path through Core.

## Completed Outcome

- `silica-storage` stores AI result rows in the existing `ai_results` table.
- Result rows default to `approved = false`.
- Stored payloads use `schema = silica.ai_result`, `version = 1`, `local_only = true`, and `permission_id = ai_result:propose`.
- Storage rejects output payloads that directly include edit graph or photo flag mutation keys.
- `silica-core` exposes local store/read functions.
- No model loading, inference, approval conversion, edit graph mutation, edit history write, or catalog flag mutation was added.

## Verification

Use:

```bash
cargo test -p silica-storage -p silica-core -p silica-mlx
scripts/harness/check.sh
```
