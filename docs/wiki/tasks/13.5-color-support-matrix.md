# Task 13.5: Color Support Matrix

## Goal

Update the color support matrix from actual Class F probe evidence.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Color Management](../topics/color-management.md)
- [Task 13.4 Color Probe Harness](13.4-color-probe-harness.md)

## Files

- `docs/wiki/topics/color-management.md`
- `docs/wiki/log.md`
- Relevant task cards if statuses change

## Scope

- Record fixture-backed states for tagged sRGB, tagged Display P3, and untagged raster.
- Record failures as explicit blocked states.
- Keep color correctness blocked unless tolerance and visual review gates are satisfied.
- Keep Display P3 export disabled unless later ICC export proof passes.

## Acceptance Criteria

- The matrix records fixture id, subclass, input profile, working space, output profile, probe status, original hash result, and evidence source.
- Failed or missing fixture classes remain blocked.
- No broad product color claim is added.
