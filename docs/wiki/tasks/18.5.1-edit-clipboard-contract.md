# Task 18.5.1: Edit Clipboard Contract

## Goal

Define the typed copy/paste edit subset contract before batch sync mutates multiple photos.

## Read Before Work

- [Task 18.4.3 Lens Geometry Panel UI QA](18.4.3-lens-geometry-panel-ui-qa.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Edit Graph](../topics/edit-graph.md)
- [Action Trust](../topics/action-trust.md)

## Files

- `crates/silica-edit/src/lib.rs`
- `crates/silica-core/src/lib.rs`
- `docs/wiki/topics/edit-graph.md`

## Scope

- Define copyable edit sections by schema-owned groups.
- Let users choose subsets such as basic, tone, color, detail, lens, and geometry.
- Preserve target photo source/profile/metadata identity.
- Never copy `source`, `source.fingerprint`, target photo identity, or target profile evidence from the source photo.
- Reject arbitrary JSON patching and extension-owned mutation.
- Do not add batch UI, storage mutation, sidecar writes, plugin hooks, or MCP access.

## Acceptance Criteria

- Copy/paste payloads are typed and validate before application.
- Target identity fields are preserved.
- Invalid subset requests are rejected.
- No catalog mutation happens in this contract-only task unless explicitly needed for tests.

## Validation

```bash
cargo test -p silica-edit -p silica-core
scripts/harness/check.sh
```

## Stop Gates

Stop if copy/paste would allow raw JSON patches, source identity replacement, plugin mutation, or sidecar writes.
