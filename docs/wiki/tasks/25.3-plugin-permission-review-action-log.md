# 25.3: Plugin Permission Review and Action Log

## Scope

Add plugin enable/apply review evidence without starting a plugin runtime.

## Completed Outcome

- `silica-core` exposes plugin permission review helpers for enable decisions and apply denials.
- Enable review validates the plugin manifest, checks the requested permission, and appends `permission_grant` or `permission_denial`.
- Apply review validates the plugin manifest, checks `edit_suggestion:apply`, and appends `plugin_apply` evidence.
- Permission review does not persist grants, start runtime, write edit state, write history, write exports, write sidecars, or mutate originals.
- Preferences Advanced shows the static plugin permission review contract beside the existing prompt contract.
- Plugin code still cannot directly access SQLite.
- Permission denial is logged and leaves catalog edit state unchanged.

## Validation

Use:

```bash
cargo test -p silica-core plugin_permission_review_logs_grants_and_denials_without_state_mutation
python3 scripts/harness/check-static-ui.py
scripts/harness/check.sh
```
