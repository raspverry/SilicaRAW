# Task 13.3: Feature-Gated Color Profile Probe

## Goal

Add a non-default `color-probe` feature path that records color profile evidence without changing normal product behavior.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Color Management](../topics/color-management.md)
- [Spike 003](../../spikes/003-color-managed-preview-export.md)
- [Dependencies Policy](../../DEPENDENCIES.md)

## Files

- `crates/silica-render`
- `docs/DEPENDENCIES.md` if any dependency is added or changed
- Relevant docs if API behavior changes

## Scope

- Feature gate name: `color-probe`.
- The feature must be non-default.
- Probe result records source path, source SHA-256, input profile classification, working space, output profile, transform path, platform, and message.
- Untagged raster behavior must be explicit as `assume_srgb`.
- Normal preview, export, and UI behavior must not call the probe.

## Acceptance Criteria

- Default workspace build remains unaffected.
- Unsupported platforms return unavailable or blocked states without changing local alpha behavior.
- Any new macOS or ICC/profile dependency is documented in `docs/DEPENDENCIES.md`.
- No color correctness claim is added.

## Validation

```bash
cargo test -p silica-render --features color-probe
scripts/harness/check.sh
```

## Completion State

Not started.

## Stop Gates

Stop before implementation if profile inspection requires a large dependency, unclear license, or broad parser fallback.
