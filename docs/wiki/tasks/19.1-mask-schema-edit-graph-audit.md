# Task 19.1: Mask Schema and Edit Graph Audit

## Goal

Audit the existing edit graph mask schema and Rust graph representation before adding mask UI, preview, export, storage, or cache behavior.

## Read Before Work

- [Phase 19 Brief](../phases/phase-19-manual-masks.md)

## Scope

- Audit current `masks` schema fields, supported mask `type` values, `source.kind` provenance values, and `local_adjustments` shape.
- Decide whether Phase 19 manual masks can use the existing schema without a breaking schema change.
- Add or adjust typed Rust edit graph support only where required for validation and round-trip behavior.
- Record manual mask versus future AI/MLX provenance boundaries.
- Do not implement preview, export, storage caches, UI screens, brush rasterization, MLX, MCP, or plugin behavior.

## Acceptance Criteria

- The existing mask schema is documented as sufficient or an explicit schema-change decision is recorded.
- Manual mask provenance uses `source.kind = "manual"` and future AI/MLX provenance remains distinct.
- `silica-edit` can validate and round-trip the accepted manual mask shape.
- Invalid mask types, invalid ranges, or malformed required fields are rejected before runtime behavior.
- Task 19.2 has a clear schema contract to build against.

## Validation

```bash
cargo test -p silica-edit
scripts/harness/check.sh
```

## Stop Gates

Stop if manual masks require fields that are not in the authoritative schema and no explicit schema decision exists.
