## Goal

Audit the existing edit graph mask schema and Rust graph representation before adding mask UI, preview, export, storage, or cache behavior.

## Scope

- Audit current `masks` schema fields, supported mask `type` values, `source.kind` provenance values, and `local_adjustments` shape.
- Decide whether Phase 19 manual masks can use the existing schema without a breaking schema change.
- Add or adjust typed Rust edit graph support only where required for validation and round-trip behavior.
- Record manual mask versus future AI/MLX provenance boundaries.
- Do not implement preview, export, storage caches, UI screens, brush rasterization, MLX, MCP, or plugin behavior.

## Acceptance Criteria

- The existing mask schema is documented as sufficient or an explicit schema-change decision is recorded.
- Manual mask provenance uses `source.kind = "manual"` and future AI/MLX provenance remains distinct.
- `silica-edit` can validate and round-trip the accepted manual mask shape.
- Invalid mask types, invalid ranges, or malformed required fields are rejected before runtime behavior.
- Task 19.2 has a clear schema contract to build against.

## Completion Notes

Task 19.1 records an explicit v0.1 schema completion before any mask UI, preview, export, storage, or cache behavior exists.

- Manual linear and radial masks use `masks[].geometry` as the durable schema-owned geometry location.
- `linear_gradient` and `radial_gradient` masks require matching geometry; other mask types cannot carry geometry until their durable shape is defined.
- Manual provenance uses `source.kind = "manual"` and manual sources stay provenance-only. Cache paths, model identifiers, AI result identifiers, arbitrary source extensions, and hidden geometry-in-source are rejected by `silica-edit`.
- Brush mask storage remains deferred to Task 19.3. Raster/cache artifacts are disposable and cannot be the durable brush source of truth.
- No preview, export, storage cache, UI, brush rasterization, MLX, MCP, plugin, sidecar write, or original-file behavior was added.

## Task 19.2 Contract

Task 19.2 must build linear/radial helpers against:

```txt
masks[].type = "linear_gradient"
masks[].geometry.kind = "linear_gradient"
masks[].geometry.start_x/start_y/end_x/end_y = normalized 0..1 frame coordinates

masks[].type = "radial_gradient"
masks[].geometry.kind = "radial_gradient"
masks[].geometry.center_x/center_y = normalized 0..1 frame coordinates
masks[].geometry.radius_x/radius_y = normalized >0..1 radii
masks[].geometry.rotation = -180..180 degrees

masks[].source = {"kind": "manual"}
```

Task 19.2 must still define which `local_adjustments` keys and ranges it can honestly preview and commit; unsupported local adjustments must be blocked rather than ignored.
