# Task 18.3.1: Detail Mutators

## Goal

Add schema-valid edit graph mutators for sharpening and non-MLX noise reduction controls.

## Read Before Work

- [Task 18.2.3 HSL Panel UI QA](18.2.3-hsl-panel-ui-qa.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Edit Graph](../topics/edit-graph.md)
- [Edit Graph Schema](../../../schemas/edit_graph.schema.json)

## Files

- `crates/silica-edit/src/lib.rs`
- `docs/wiki/topics/edit-graph.md`

## Scope

- Add typed mutators for sharpening amount, radius, detail, and masking.
- Add typed mutators for luminance/color noise reduction values in the schema.
- Leave `detail.mlx_denoise` unchanged and inert.
- Do not add preview, export, UI, storage, sidecar, MLX runtime, or model behavior.

## Acceptance Criteria

- Detail edits can be applied to an existing edit graph.
- Invalid values are rejected.
- Edited graphs validate and round-trip.
- MLX denoise remains deferred and unimplemented.

## Validation

```bash
cargo test -p silica-edit
scripts/harness/check.sh
```

## Stop Gates

Stop if the task would add MLX, model loading, or fake denoise support.
