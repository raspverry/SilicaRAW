# Task 13.4: Color Probe Harness

## Goal

Run legal Class F fixtures through the feature-gated color probe and record original-preservation evidence.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Task 13.2 Local Color Fixture Corpus and Manifest](13.2-color-fixture-local-manifest.md)
- [Task 13.3 Feature-Gated Color Profile Probe](13.3-feature-gated-color-profile-probe.md)

## Files

- `crates/silica-render`
- `scripts/harness/check-color-probe-fixtures.py`
- `docs/wiki/topics/color-management.md`

## Scope

- Add an ignored test path driven by `SILICARAW_COLOR_FIXTURE_MANIFEST`.
- Validate manifest safety before probing.
- Record input profile, working space, output profile, transform path, source hash, file size, modified time, status, and error category.
- Verify source SHA-256 remains unchanged after probing.

## Acceptance Criteria

- Harness fails clearly when the manifest is absent, unsafe, incomplete, or hash-mismatched.
- Fixture originals remain unchanged before and after probe.
- Probe output is structured enough to update the color support matrix.

## Validation

```bash
SILICARAW_COLOR_FIXTURE_MANIFEST=... scripts/harness/check-color-probe-fixtures.py
scripts/harness/check.sh
```

## Completion State

Complete as of 2026-06-12.

Task 13.4 added:

- `scripts/harness/check-color-probe-fixtures.py`
- `crates/silica-render/examples/color_probe_report.rs`

The harness reads `SILICARAW_COLOR_FIXTURE_MANIFEST`, validates a local Color Class F manifest, runs the feature-gated `silica-render` color probe for each fixture, and records structured output for:

- input profile
- working space
- output profile
- transform path
- source SHA-256
- file size
- modified time
- status
- error category
- original hash preservation

The local fixture run passed for:

```txt

untagged_jpeg -> success, none, assume_srgb path, original hash unchanged
```

No color correctness, ColorSync transform, export ICC embedding, or pixel-rendering claim was added.

## Stop Gates

Stop if the harness needs committed fixture media, fake profile evidence, or original-file mutation.
