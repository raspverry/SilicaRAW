## Scope

- Promote preview artifact identity into a native viewer texture request.
- Preserve latest-request-wins behavior.
- Keep web controls usable outside the reserved viewer rectangle.
- Keep unsupported RAW state visible and reviewable.
- Keep feature-gated native viewer behavior out of default CI unless explicitly documented.

## Acceptance Criteria

- Preview artifact can become a native viewer texture identity.
- Latest request wins during selection or viewport changes.
- Web controls outside the reserved viewer rectangle remain usable.
- No export path depends on viewer texture cache.

## Validation

```bash
cargo test -p silica-render
cargo test -p silica-desktop --features native-metal-viewer
scripts/harness/check.sh
```

## Completion State

Completed on 2026-06-12.

Task 15.3 added:

- `ViewerTextureIdentity::from_preview_request` to promote `DecodedImageArtifact` preview requests into disposable native viewer texture identity.
- Viewport-backed drawable size calculation for request-scoped texture identity.
- Native viewer bridge binding of decoded artifact texture identity with latest-request-wins scheduling.
- Stale texture clearing when the latest request is blocked by decode.
- Smoke evidence that records decoded artifact texture identity without carrying image bytes or writing catalog/export state.

Next task: [Task 15.4 Exposure/Contrast Metal Draft Path](15.4-exposure-contrast-metal-draft-path.md).

## Stop Gates

Stop if native viewer display requires arbitrary web overlay coverage, breaks web controls, or makes viewer texture cache the export source of truth.
