# Task 18.5.2: Batch Sync History

## Goal

Apply validated edit subsets across selected photos with one undoable history checkpoint per affected photo.

## Read Before Work

- [Task 18.5.1 Edit Clipboard Contract](18.5.1-edit-clipboard-contract.md)
- [Phase 18 Brief](../phases/phase-18-professional-editing-baseline.md)
- [Catalog](../topics/catalog.md)
- [Data Safety](../topics/data-safety.md)
- [Action Trust](../topics/action-trust.md)

## Files

- `crates/silica-core/src/lib.rs`
- `crates/silica-storage/src/lib.rs`
- `crates/silica-edit/src/lib.rs`
- `apps/desktop/src-tauri/src/main.rs`

## Scope

- Apply selected edit subsets to multiple catalog photos.
- Record one undoable checkpoint per affected photo.
- Keep redo invalidation consistent with Phase 16 rules.
- Preserve originals, source identity, and sidecar explicit-write policy.
- Do not add collection-wide background jobs, plugin/MCP access, or automatic sidecar writes.

## Acceptance Criteria

- Batch sync validates every target before commit.
- Partial failure behavior is deterministic and documented by tests.
- Each affected photo has its own undoable history row.
- Original files remain unchanged.

## Validation

```bash
cargo test -p silica-storage -p silica-core -p silica-edit
scripts/harness/check.sh
```

## Stop Gates

Stop if batch sync cannot be expressed as catalog transactions with clear per-photo history.
