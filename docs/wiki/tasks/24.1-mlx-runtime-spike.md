# 24.1: MLX Runtime Spike

## Scope

Record the first post-alpha MLX runtime decision without enabling MLX runtime behavior.

## Completed Outcome

- ADR 0009 records the runtime spike.
- `silica-mlx` records a typed Task 24.1 decision.
- Future first binding path is the official MLX C API behind a non-default Rust feature gate.
- Python MLX is rejected for product runtime packaging.
- MLX Swift remains a fallback if the app shell changes.
- No-model behavior is AI unavailable, editor usable.
- Memory policy is bounded worker use under Apple Silicon unified-memory pressure.
- Cancellation policy is cooperative at queued task boundaries until a future runtime probe proves stronger behavior.
- No model can be bundled or enabled without a valid manifest.
- No MLX dependency, model loader, inference worker, model asset, or UI was added.
