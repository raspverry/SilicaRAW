# Task 12.2: RAW Fixture Probe Harness

## Goal

Run legal RAW fixtures through the feature-gated Core Image probe and record structured results.

## Read Before Work

- [Phase 12 RAW Proof Brief](../phases/phase-12-raw-proof.md)
- [RAW Decoding](../topics/raw-decoding.md)
- [Schema Reference](../../19_Schema_Reference.md)
- [Fixture Manifest Schema](../../../schemas/fixture_manifest.schema.json)

## Files

- `crates/silica-decode`
- `scripts/harness/`
- `docs/wiki/topics/raw-decoding.md`
- Legal fixture manifest path supplied through `SILICARAW_RAW_FIXTURE_MANIFEST`

## Scope

- Probe only fixtures declared by a legal fixture manifest.
- Record backend, macOS version, source hash, dimensions, orientation, success/failure, and error category.
- Verify original file hashes remain unchanged.
- Keep unsupported fixture classes explicitly blocked.

## Acceptance Criteria

- Results are structured enough to update the support matrix in Task 12.3.
- Missing or invalid fixture manifest fails clearly.
- User photos or unlicensed samples are not committed.
- Unsupported classes remain blocked, not silently skipped as success.

## Validation

```bash
SILICARAW_RAW_FIXTURE_MANIFEST=... cargo test -p silica-decode --features core-image-raw-probe -- --ignored
scripts/harness/check-raw-probe-fixtures.py
scripts/harness/check.sh
```

## Current State

Harness implementation is present as of 2026-06-12:

- `probe_raw_fixture_manifest` parses a feature-gated legal fixture manifest.
- The loader rejects absolute paths, dot segments, missing `expected_source_hashes`, fixtures without `kind: "raw"`, missing RAW metadata, and mismatched `integrity.sha256`.
- The ignored Rust test verifies that probed originals keep the same SHA-256 before and after the probe.
- `scripts/harness/check-raw-probe-fixtures.py` runs the ignored test when `SILICARAW_RAW_FIXTURE_MANIFEST` points to an absolute local manifest path.
- The harness now emits a JSON probe report after the ignored test passes.

Fixture execution is complete locally for Task 12.5 classes A-D. Do not use `.tmp` blocked placeholder RAW files as evidence.

## Stop Gates

Stop if no legal fixture manifest is available, if any fixture license is unclear, or if probe evidence cannot preserve source hashes.

## Notes for LLM Agents

This task proves fixture behavior. It does not make RAW files visible in the product UI.
