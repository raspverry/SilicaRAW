# Task 13.1: Color Fixture Source Review

## Goal

Find legally usable Color Class F fixtures before any local color probe is run.

## Read Before Work

- [Phase 13 Color Pipeline Proof Brief](../phases/phase-13-color-pipeline-proof.md)
- [Color Management](../topics/color-management.md)
- [Fixture Manifest Schema](../../../schemas/fixture_manifest.schema.json)

## Files

- `docs/wiki/sources/`
- `docs/wiki/topics/color-management.md`
- `docs/wiki/log.md`

## Scope

- Review at least one tagged sRGB JPEG candidate.
- Review at least one tagged Display P3 JPEG candidate.
- Review at least one untagged JPEG candidate.
- Record source URL, license, rights holder, privacy notes, fixture intent, and expected profile state.

## Acceptance Criteria

- Every accepted fixture has clear redistribution or local-only use permission.
- Unclear or restrictive licenses are rejected.
- User photos are not used unless explicitly approved and documented as local-only private fixtures.
- No fixture media is committed in this task.
