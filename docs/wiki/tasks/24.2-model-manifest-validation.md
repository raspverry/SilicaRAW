# 24.2: Model Manifest Validation

## Scope

Validate optional model manifests before any model can be enabled.

## Completed Outcome

- `schemas/model_manifest.schema.json` requires:
  - `license`
  - `source`
  - `file_hash` as `sha256:<64 lowercase hex chars>`
  - `input.preprocessing`
  - `output.metadata`
- `silica-mlx` validates `silica.model` v1 manifests.
- Candidate model bytes are hashed with deterministic SHA-256 and compared to the manifest.
- Models remain optional.
- Passing validation does not load a model, run inference, start a worker, add MLX runtime, or make AI required.

## Verification

Use:

```bash
cargo test -p silica-mlx
python3 scripts/harness/check-md-links.py
scripts/harness/check.sh
```
